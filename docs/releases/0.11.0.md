# 0.11.0 — Social icons and custom images

## Status

Published npm `@anglefeint/astro-theme@0.11.0` and delivered the matching public starter on 2026-10-06.

- npm source / `v0.11.0` target: `bd4518948f1a316246124de450db6bc78c2ce1df`.
- Delivered starter: `238e2b824308ee8636045d798a6966f48422b034`.
- The nine bundled configuration guides were synchronized in main `fce3715a34f2df4c0da5a7de7bec24813f8a064b`, before starter generation. These content-only changes do not alter the npm package.
- Registry latest and exact-version tarball verified; SHA-1 `40a4a59ae324b0a1745a5de254d7056b2e711510` matches the prepared/published package. npm accepted one publication; only registry verification was retried during processing.
- [GitHub Release](https://github.com/anglefeint/astro-theme-anglefeint/releases/tag/v0.11.0). The tag identifies the package source, not the subsequent documentation closeout.

## Changes

- Add exactly YouTube, Bluesky, LinkedIn, Discord, Telegram, Instagram, Facebook, WhatsApp and LINE. Existing Mastodon, Twitter bird and GitHub paths remain unchanged. Selected Bootstrap Icons v1.13.1 paths are bundled with their MIT notice; no new dependency or client script.
- Configure the existing `social.links` list once for header and footer. Optional `iconSrc` overrides `icon`; omit both for text. Support local SVG/PNG/WebP under Astro's publicDir with automatic base prefix, file checks and clear configuration errors. Remote URLs, query/fragment/encoded paths and traversal are unsupported.
- Preserve menu color/hover for built-ins, original image colors for custom files, configured order and the three empty placeholders. Add footer wrapping, a horizontally scrollable header row when crowded, and visible keyboard focus. Header social links remain hidden at widths <=720px; footer links remain available.
- Synchronize setup instructions in nine READMEs and nine bundled configuration guides, architecture, visual contracts, acceptance coverage and upgrade notes.

## Upgrade

Requires matching starter schema for the expanded `SocialLink` type. npm alone does not update that local file. Target `@anglefeint/astro-theme@^0.11.0`; the `^0.10.0` range excludes it. No adapter, route, article or locale changes are required. New projects configure only `src/site.config.ts`; no platform is enabled automatically. See [UPGRADING.md](../../UPGRADING.md) for the supported fresh-template baseline and the precise schema delta for customized projects.
