# 0.11.0 — Social icons and custom images

## Status

Release preparation; publication and starter delivery are not yet complete.

## Changes

- Add exactly YouTube, Bluesky, LinkedIn, Discord, Telegram, Instagram, Facebook, WhatsApp and LINE. Existing Mastodon, Twitter bird and GitHub paths remain unchanged. Selected Bootstrap Icons v1.13.1 paths are bundled with their MIT notice; no new dependency or client script.
- Configure the existing `social.links` list once for header and footer. Optional `iconSrc` overrides `icon`; omit both for text. Support local SVG/PNG/WebP under Astro's publicDir with automatic base prefix, file checks and clear configuration errors. Remote URLs, query/fragment/encoded paths and traversal are unsupported.
- Preserve menu color/hover for built-ins, original image colors for custom files, configured order and the three empty placeholders. Add footer wrapping, a horizontally scrollable header row when crowded, and visible keyboard focus. Header social links remain hidden at widths <=720px; footer links remain available.
- Synchronize setup instructions in nine READMEs, architecture, visual contracts, acceptance coverage and upgrade notes.

## Upgrade

Requires matching starter schema for the expanded `SocialLink` type. npm alone does not update that local file. Target `@anglefeint/astro-theme@^0.11.0`; the `^0.10.0` range excludes it. No adapter, route, article or locale changes are required. New projects configure only `src/site.config.ts`; no platform is enabled automatically. See [UPGRADING.md](../../UPGRADING.md) for the supported fresh-template baseline and the precise schema delta for customized projects.

## Validation and delivery

- Main lint and checks passed: 85 unit tests, 65 maintained documents, no Astro errors/warnings, 190 generated pages, 126 indexed articles and nine About runtime checks. The final source is checked again by the required pre-push hook.
- Independent packed-starter installation/audit and 14 build variants passed, including all nine locales, twelve built-in social names, a PNG override and a text link in both menus; empty configuration is exercised separately. Dependency audit reported zero known vulnerabilities.
- 34 existing Chromium E2E tests passed. A separate temporary Astro project exercises four actual page shells at 1280/900/721/720/390/320px with twelve icons, SVG/PNG/WebP overrides and text; verifies image loading, order, keyboard focus, mobile visibility and no new page overflow/navigation overlap. Another build checks custom publicDir/base, placeholders and missing-file diagnostics. Initial fixture path/route errors and the crowded-header wrapping defect were corrected before acceptance.
- At 721px, Home and the selected article have 26px/22px of existing main-content overflow, respectively; hiding both social menus does not change it. Their main-content styles were not changed in this release. This is recorded separately, not claimed as fixed or as a passing zero-overflow assertion.
- Documentation review followed `suggest:docs`, source/default/caller checks and metadata validation. All nine READMEs describe current behavior; unrelated workflow rules and historical releases were left intact.
- GitHub workflow triggers were inspected (template acceptance is manual). Cloudflare account-side branch/deploy settings are not accessible in this session; successful GitHub checks and live inventory will be reported separately, without claiming those settings were verified.

Publication, remote-template acceptance and final source/starter revisions remain to be recorded after delivery.
