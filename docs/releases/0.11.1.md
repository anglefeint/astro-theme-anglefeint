# 0.11.1 — Reading-panel width correction

## Status

Release preparation; publication and delivery are pending validation.

## Changes

Fix the overflow recorded during 0.11.0 acceptance. At 721px, Home previously extended 26px past the viewport and the representative article extended 22px. Desktop width limits subtracted less than the actual padding/borders added by the scene styles. Both maximum widths now reserve those dimensions above 720px. This retains the 720px wide-screen content width and all existing mobile rules, effects and animations, without global overflow clipping.

Only two package-owned CSS files change at runtime. No dependency, JavaScript, routing, SEO or configuration changes.

## Upgrade

Compatible package-only patch for matching 0.11.0 starters:

```bash
npm update @anglefeint/astro-theme
npm run doctor
npm run build
npm run preview
```

Rebuild and redeploy the site. No schema, adapter, route or article edits are needed for this patch. Earlier-version migration requirements are unchanged; see [UPGRADING.md](../../UPGRADING.md).

## Validation and delivery

- Lint, 85 unit tests, documentation checks for 66 maintained documents and Astro checks passed (zero errors/warnings). Main builds 190 pages with 126 indexed articles.
- All 43 Chromium E2E tests passed, including nine new reading-width tests: nine languages × Home/representative article × 320/390/720/721/740/768/800/820/900/1440px. They check page/panel containment and the 720px wide-screen content width. Existing interaction, navigation, SEO and reduced-motion checks also passed.
- Direct before/after measurements confirmed zero overflow at the previously failing widths; actual panel geometry at 720px and 900px is unchanged. Screenshots cover mobile, breakpoint and wide-screen layouts. An initial visual helper compared the intentionally changed max-width expression and waited for an animated panel to become stable; those helper assumptions were corrected, without altering page animations.
- Code-first documentation review updated visual contracts, upgrading and release records. Setup/configuration and the nine READMEs/guides remain valid without edits.

Independent package, registry, starter and public-template results will be recorded after delivery. Cloudflare account-side build branch settings are not directly accessible in this session; check results and live demo verification will be recorded separately.
