# 0.11.2 — Grouped, localized footer

## Status

Release preparation; external delivery remains pending verification.

## Changes and compatibility

- Separate copyright, theme/Astro credits and optional custom tagline into independent groups, followed by social icons. Smaller secondary type, a 720px content cap and wrapping keep the footer compact. Four scene palettes and effects remain intact; footer paragraphs inherit footer colors rather than Home prose colors.
- Translate built-in credits into all nine built-in languages via the existing message resolver; keep Anglefeint/Astro brand names and link destinations. No new browser script or dependency.
- Preserve `site.tagline`, `PUBLIC_SITE_TAGLINE` precedence, `theme.footer.showCredits`, legacy `Built with Astro.` deduplication and optional component-prop fallbacks. User text is not translated or replaced. Empty text renders no row. No copyright/hosting statement is added to defaults; the screenshot statement exists only in an ignored test fixture.
- Compatible package-only patch for matching 0.11.0/0.11.1 starters: no schema, adapter, route or configuration migration. Older migration requirements remain in [UPGRADING.md](../../UPGRADING.md).
- Synchronize nine READMEs, nine configuration guides, package README, visual/acceptance references and documentation audit evidence. Starter delivery includes documentation and dependency updates.

```bash
npm update @anglefeint/astro-theme
npm run doctor
npm run build
npm run preview
```

Rebuild and redeploy to apply the update.

## Validation

- Implementation validation passed: lint, 85 unit tests, Astro checks (zero errors/warnings), build and documentation checks. The complete 52-test Chromium suite passed; after the final footer paragraph-color correction, the final build and all 11 footer tests passed again. Nine languages, four page types and 1440/721/390/320px are covered.
- An isolated real-component fixture passed 20 cases for ordinary, long unbroken, empty and legacy taglines plus omitted-label fallback. Desktop/mobile screenshots were reviewed. Existing user configuration and default-empty behavior remain unchanged.
- Independent packed-starter installation, CLI/adapter checks, zero-vulnerability audit and all 14 build variants passed before release preparation. Release dry-run/publication reuse these completed checks with `--skip-checks`; mandatory audits and isolated installation/CLI checks still run. Required main/starter push hooks also run full checks/builds.
- Documentation review used explicit working-tree inputs with `suggest:docs`, implementation/default/caller checks and local document/guide-route validation. Historical release evidence was not rewritten.
- No Firefox/WebKit, pnpm/Linux acceptance or Cloudflare account-side branch/deployment setting verification is claimed here. Registry, delivered starter, public-template and live deployment results will be recorded after delivery.
