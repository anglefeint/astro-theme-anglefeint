# 0.11.3 — About line breaks

## Status

Release preparation; delivery remains pending verification.

## Changes and upgrade

Direct About body paragraphs and the signature preserve actual configuration line feeds with `white-space: pre-line`. One line feed starts a new line; two leave a blank line. Long sentences still wrap. Literal backslash-plus-n text is not a line feed. Markdown/HTML are not parsed; do not insert `<br>`. Headings, list items, sidebar labels, modals and effects are unchanged.

The only runtime change is scoped package CSS. Compatible package-only patch for matching 0.11.x starters; no schema, adapter, route or configuration migration. Existing literal line feeds that previously collapsed will now be visible. Earlier upgrade requirements remain in [UPGRADING.md](../../UPGRADING.md).

```bash
npm update @anglefeint/astro-theme
npm run doctor
npm run build
npm run preview
```

Redeploy after building. Nine READMEs and nine optional-feature guides document the same plain-text behavior.

## Validation

- All 55 Chromium E2E tests passed, including three new About geometry checks at 1440/390/320px for blank-line spacing, long-sentence wrapping and unaffected heading/sidebar whitespace. Existing About interactions and nine-language checks passed.
- The installed-starter fixture supplies real multiline configuration and checks emitted HTML separately from browser geometry. Its first attempt was stopped by an invalid npm audit service response; the safety gate was retained and the run retried.
- The isolated installed-starter retry passed all 14 build variants and dependency audit (zero known vulnerabilities), including actual multiline configuration output assertions. Lint and `check:no-build` passed with 85 unit tests and zero Astro errors/warnings. An initial unit run encountered an incomplete Pagefind JSON file; the unchanged suite passed on retry. The mandatory full pre-push check will run again before publication.
- Registry, public-template and deployment results will be recorded after completion. Cloudflare account-side build settings cannot be directly inspected here; browser coverage is Chromium, not Firefox/WebKit.
