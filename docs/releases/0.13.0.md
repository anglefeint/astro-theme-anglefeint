# 0.13.0 — Global mathematical formulas

## Status

Release preparation; publication and delivery are not yet complete.

## Changes and migration

Markdown and MDX article mathematics is globally enabled in the new starter. Write `$...$` inline or `$$` on separate lines for display math. No frontmatter flag is needed. Sätteri parses formula nodes and a package-owned adapter uses KaTeX at build time, retaining HTML and MathML. Styles and fonts are local; no browser math engine is added. Display formulas scroll horizontally. Formula subtrees are excluded from Pagefind to avoid indexing duplicate representations; surrounding prose remains searchable.

`theme.math.enabled: false` disables parsing and formula stylesheet links. Code spans/blocks remain literal; escape ambiguous dollar amounts as `\$`. When disabled, ordinary MDX rules apply again, including JavaScript expressions in braces. This is KaTeX's supported mathematics, not arbitrary LaTeX documents. Invalid formulas stop compilation with file context and the renderer's error; source-node positions are included when available. Title, description, RSS summaries and share-card text remain plain text.

This is a minor feature release requiring starter/configuration migration. See the exact [0.12.0 migration steps](../../UPGRADING.md#0130-global-markdown-and-mdx-mathematics); prefer a fresh starter for older or substantially customized projects. Installing the theme alone does not change an existing Astro processor. New users create the delivered starter with:

```bash
npm create astro@latest -- my-blog --template anglefeint/astro-theme-anglefeint#starter
```
