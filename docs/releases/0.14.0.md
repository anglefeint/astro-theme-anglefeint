## Changes and migration

Home adds sequential `Initialize... done.` and `Wake Up... Follow The White Rabbit...` terminal messages, four shuffled rabbit decoders across post/all-posts links, and a local cracked mirror that refracts the live rain, becomes liquid on hover and repairs on click for the rest of the visit. Refresh restores the cracks. The homepage passage is disabled by default through `theme.effects.enableHomePassage`; enabling it plays an 8-second green corridor/door/digital courtyard before post navigation. The all-posts link keeps native navigation.

About adds an independent Oracle preview: palette selection happens at click time, using Matrix green, Cyber blue/lilac, AI cyan/pink or Hacker silver/amber without immediately repeating the previous palette. Click again or press Escape to return; the scene continues after arrival until dismissed. A digital bench, seated Oracle back silhouette and randomized articulated birds appear on open ground fading into darkness. Movement and geometry are independent modules; no movie screenshot is used as a scene billboard.

Homepage startup owns one rain loop and coordinates independent controllers. Hidden pages suspend work, cached history returns preserve state, live reduced-motion changes update behavior, and actual teardown disposes listeners, timers, canvas backing stores and GPU resources. Repaired mirrors stop sampling; texture updates reuse storage. Cursor blinking is finite. Music scene styles and optional Matrix reflection/ripple effects are separated from audio playback.

This is a minor feature release with starter configuration/route migration. Prefer a fresh template in a new directory and migrate personal settings/content. Matching 0.13.0 projects may merge the schema/defaults/adapter, About route and script declaration changes described in [UPGRADING](../../UPGRADING.md#0140-matrix-homepage-and-oracle). Package installation alone does not create the new About button. No new audio setting, locale route or SEO contract is introduced. Reduced motion keeps native home navigation and a static Oracle preview; WebGL failure preserves normal navigation/About access.

Its blocking audit reported zero vulnerabilities. Evidence: `acceptance-results/release-0140-installed.log`.
