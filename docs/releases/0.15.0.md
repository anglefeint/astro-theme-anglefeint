## Changes and migration

Three independent switches under `theme.home` default to true: `showInitialize` controls Initialize/done, `showFollow` controls Wake Up/Follow, and `showTrace` controls the lower-right terminal status. Disabled sections are omitted from generated HTML. With startup disabled, Wake Up starts immediately. The trace appears immediately with a leading >, Courier text and a CSS block cursor blinking once per second; reduced motion keeps its cursor static. Fixed intro text uses CSS typing; dynamic JS character-width calculation is absent. Background rain and other effects remain independent.

Optional `theme.footer.links` defaults to an empty array and adds a separate dot-separated link row, independent of social icons and theme credits. Demo identity/social settings are not copied to consumer defaults.

Both the package and starter schema/defaults/adapter must be upgraded. Prefer a fresh public starter and deliberate content/configuration migration; see [upgrade steps](../../UPGRADING.md#0150-home-switches-and-footer-links). Package installation alone does not update consumer configuration files.
