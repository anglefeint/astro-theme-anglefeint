## Changes and migration

Optional `i18n.locales.<code>.site.homeTitle` controls the homepage's visible h1 in any registered language. The helper trims text and skips missing/blank values along the existing locale fallback chain, then uses `SITE_TITLE` including `PUBLIC_SITE_TITLE`. Defaults remain unset. Browser title, navigation, footer, RSS and SEO site identity retain the global site name. Text is escaped by Astro and long titles wrap within mobile bounds. No browser translation or new client script is added.

The main demo configures English `AngleFeint.` and eight localized headings. These are illustrative brand translations/transliterations, not official translations. Demo identity is not distributed to personal-blog starters.

Both package and matching starter types, normalizer and site adapter are required. Prefer a fresh template and migrate personal settings/content; old starters must add `getHomeTitle` before upgrading the package. See [migration](../../UPGRADING.md#0160-localized-homepage-headings).
