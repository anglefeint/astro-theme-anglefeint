# 0.17.0 — Keyhole terminal and shared Oracle exploration

## Status

Release preparation started on 2026-10-16 from main `baaef62`. Publication, starter delivery and remote acceptance remain pending. The final source and starter revisions will be recorded after verification.

## Changes and migration

- The wide-screen homepage terminal keeps text selectable and scrollable. A separate bottom-right keyhole reveals a bright old-style key on hover/focus; activation inserts and turns it over 600ms, keeps the unlocked pose and fades it while the terminal expands into the passage. Text clicks and hover alone do not start WebGL. Reduced motion skips insertion.
- `i18n.locales.<code>.messages.home.transmission` resolves from the current language configuration, then English configuration, then the single `Knock, knock.` default. Empty overrides remain valid. Other UI translations keep their existing fallback behavior. Demo testing text is not shipped in configuration.
- Home's inline preview and About Oracle share player, camera/door timeline, scene, materials and renderer. The preview starts with corridor-only geometry and appends the courtyard/Oracle/crows when its projected door button is activated. Dragging after arrival looks around at a fixed position; right-click returns regardless of direction. Left-click/Enter return only through the back corridor opening. About closes via Escape or ×, with keyboard focus/scroll restoration.
- Compact quality is resolved from final canvas size: 256px textures, lower glyph density and simplified cable geometry. One paused inline instance is retained for 15 seconds, then released. Hidden pages pause. Closed doors skip courtyard/Oracle/crow color and glow draws without discarding resources. Reopening and reverse travel reuse buffers, textures and programs.
- The rear corridor has four pairs of side doors and a right-angle elbow with a short transverse hall; doorway/frame/reveal code flows while metal handles remain static. The homepage wordmark, latest label, all-posts link and PIRATE SIGNAL footer gain cinematic terminal styling without changing routes or site identity.

Both package and matching starter message adapter are required. Prefer a fresh template and migrate personal content/settings; existing matching projects must merge the message adapter template and regenerate it before upgrading. No new schema field, remote service or starter-managed runtime file is required. See [migration](../../UPGRADING.md#0170-terminal-message-and-shared-oracle-exploration).
