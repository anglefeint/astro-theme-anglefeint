## Changes

- `/<locale>/decoder/` adds a full-width local workbench with Text, Token call and Address inspection tabs, localized controls, processing history/branching/export, and a fixed initially collapsed music player. About keeps the quick text decoder and a Decoder Lab entry in its shared window title bar. A persistent localized footer link and static usage guidance aid discovery.
- Shared text codecs support Base64/Base64URL, URL, UTF-8 Hex, HTML entities, Unicode escapes and JWT header/payload. JWT decoding does not verify signatures. Inputs are bounded to 16,384 UTF-16 code units, history to ten steps and 262,144 aggregate input/output code units; decoded markup remains inert text.
- Lazy local crypto modules interpret transfer/approve/transferFrom for EVM/HyperEVM and TRON, preserve uint256 amounts and use user-provided decimals. EVM/TRON/Bitcoin address inspection checks encoding/checksums and Bitcoin network/script representation. No RPC, wallet, token registry, arbitrary ABI or chain-state lookup is provided.
- One independent demand-driven numeric effect serves both hosts. Configurable total range defaults to 1500–3000ms including the final 1200ms crossfade. Short/medium/long input biases duration within that range; the actual result is computed before decoration. Colors, alpha and trails are configurable. Lab digits match result text with no trail; About uses amber/pale gold. Closing/editing/scrolling/reduced motion and navigation retain bounded cleanup.
- About’s terminal accepts a configured virtual filesystem and read-only ls/cd/pwd/cat/vi commands. Article content is loaded on demand from same-origin generated public JSON, bounded/cached and rendered in the original Canvas; :q/Escape exits reading. This is a simulated read-only filesystem, not a system shell or editor.
- About’s lifecycle, terminal, generic window, modal tools, reading effects and Oracle ownership are separated. File cards have equal heights, clamped labels, localized exact-title copy and constrained scrolling. About uses neutral/amber materials; page-scoped player transparency preserves shared playback/placement behavior.
- Localized functional titles, canonical/hreflang, sitemap, WebApplication data and no-JavaScript help use existing SEO infrastructure. Structured data has no fabricated ratings or ranking guarantee.

## Migration

Use the matching starter and package. New starter-owned Decoder and terminal-document routes are listed in the manifest; About route, defaults/schema, adapter templates/generated outputs and runtime validator/type changes must move together. `theme.enableDecoderPage` defaults to true independently of About. No unprefixed `/decoder/` alias is generated. Existing custom About labels remain configurable; old decryptor hash/passphrase labels are accepted but unused. See [upgrade guidance](../../UPGRADING.md#0180-decoder-lab-and-shared-about-modules).

Numeric animation options are internal reusable JS/CSS parameters, not new site-config fields. DL Data remains a decorative progress bar, AI a configured text dialog and Help a keyboard interaction. The discussed AI navigation directory is not included.
