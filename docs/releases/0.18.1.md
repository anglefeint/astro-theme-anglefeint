# 0.18.1 — Compact player and hidden homepage signals

> Commit references in this record follow the cleaned Git history. Published npm metadata retains original commit IDs; historical text normalization may differ from archived npm tarballs.

npm 0.18.1 and the matching public starter were delivered on 2026-10-18. Published package source/tag: `63d28c62f177375b4865d95c83bf1132a53da6f2`; starter: `fa8e1196fc7b55e0aea9379dfec7826000ff31de`, theme range `^0.18.1`. Remote-template acceptance passed. [GitHub Release](https://github.com/anglefeint/astro-theme-anglefeint/releases/tag/v0.18.1). Later documentation closeout does not change the npm source revision.

## Changes

- Enabled music players start compact in the initial HTML, avoiding an expanded flash. Custom `MusicDeck` callers can pass `initiallyCollapsed={false}` for expanded initialization on desktop or mobile, or true for compact. `ThemeFrame` forwards `musicInitiallyCollapsed`. Explicit initialization overrides viewport and stored presentation on each new page; manual controls, playback/volume resume and BFCache reconciliation remain available.
- The homepage's left pirate signal and right trace start visually hidden and reveal independently on hover or text selection. Select-all reveals both; the glowing cursor follows only the trace. Reduced motion disables reveal transitions and cursor blinking. Tighter desktop/mobile bottom padding removes excess empty space without changing reveal geometry. The separate keyhole terminal is unaffected.
- Music browser fixtures use Astro's actual preview port and cover initial HTML, explicit props and opposing saved state. Homepage Chromium tests cover independent selection/hover, select-all, unrelated selection, cursor behavior, stationary geometry and mobile/reduced-motion selection.

## Migration

This is a compatible package-only presentation update for projects already matching 0.18.0. No new site-config field, route, alias, package export or adapter contract is introduced. Run `npm update @anglefeint/astro-theme`, then `npm run doctor`, preview and redeploy. Earlier starter versions still require their existing migration steps. Music remains opt-in with a nonempty playlist. `theme.home.showTrace: false` still omits the entire status row.

Starter synchronization is required to deliver the matching dependency range/lockfile and nine-language README updates. The starter must be generated from committed main through the official release command.
