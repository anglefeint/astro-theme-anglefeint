# 0.19.0 — Cypherpunk Decoder Lab and shared effect lifetimes

## Status

npm 0.19.0 and the matching public starter were delivered on 2026-10-18. Published package source: `27caa7dca9050a1be4a3d678fc22e5597cb3c37e`; starter: `83ce65697ec02f41b6ba605fe946cc1b5dfca5c2`, theme range `^0.19.0`. Remote-template acceptance passed. [GitHub Release](https://github.com/anglefeint/astro-theme-anglefeint/releases/tag/v0.19.0). Later documentation commits do not change the npm source revision.

## Changes

- Refine Decoder Lab with a compact heading, borderless workbench composition, localized address-inspection guidance and a randomized moving SVG peer network. Connected vertices move together with signals interpolated along their current edges. Reduced motion retains a static graph; hidden pages release the active frame loop.
- Extract package-owned `NetworkBackdrop`, self-styled `WindowShell` with body/actions slots, and `mountMusicDeck(root)`. Music remains one player session with source-based track identity, saved progress/volume, pause intent and existing explicit initial-size priority; this is not concurrent multi-player support.
- Keep Oracle's shared matrix-passage engine and the virtual terminal's existing engine/adapter boundary. Extract Home signal-preview interaction and About title reveal. Isolate optional Home/About initialization and cleanup failures. Article effects return disposers and cancel listeners, timers, frames, idle work, observers and image callbacks on teardown; cached documents retain their visibility-based recovery.
- Add concise cypherpunk tribute text to nine-language READMEs and the package README. Expand the nine-language starter guide with the conviction that privacy and freedom cannot rely solely on those in power, and the original manifesto's “Cypherpunks write code”.
- Fix the maintainer drift-check exit path to release its session lock even when reporting expected drift; all blocking checks remain unchanged.
- Exclude ignored local audit copies from maintainer TypeScript discovery; keep shipped source checking and all release gates.

## Migration

Starter sync delivers the dependency range/lockfile and managed README/tutorial updates; package runtime stays in npm rather than being copied into starter.
