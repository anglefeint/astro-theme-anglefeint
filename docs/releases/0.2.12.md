# Release Notes: 0.2.12

## Package Changes

- Post scaffolding executes the actual TypeScript site configuration using Jiti, including imports and normalized language defaults.
- Invalid configuration reports an error instead of silently creating English posts. Explicit locale overrides remain independent of configuration loading.
- Existing posts are not overwritten; missing locale arguments fail clearly.
- Reduced-motion mode hides the animated side monitor without loading its playlist.
- Package exports include the configuration loader used by installed-project adapter checks.

## Starter Delivery

- Starter scripts/dependencies are generated explicitly without workspace or maintainer hooks.
- Managed output includes root routing, sitemap configuration, content schema, CJK metrics and required support scripts.
- Adapter checks execute real installed-package configuration. Known legacy patterns have read-only diagnostics.
- Windows content cleanup and push retries are corrected; source/main sync targets are rejected.
- Starter sync is required after npm publication. New users should use the latest `#starter` template.

## Existing Projects

For the complete updated skeleton, create the latest template in a new directory, then migrate articles, assets and personal settings. Keep the old project until the new one is verified. Do not replace new config helpers or lockfiles wholesale with old copies. See `UPGRADING.md`.

Compatible package-only updates remain possible, but this release does not guarantee automatic in-place migration of every historical starter. npm updates do not modify project-owned files.

## Release Gates

- Source: the main release-preparation commit introducing this version; the final delivery record identifies main and starter commits.
- Before publishing: `npm run lint`, `npm run check`, `npm run check:installed -- --build`, `npm run e2e`, and release dry-run.
- After publishing: verify npm registry installation and generated starter checks/build.
- Final acceptance: create from remote `#starter`; exercise npm/pnpm installation, doctor/check, scaffold commands, build, dev and preview; stop servers and remove temporary projects after success.

The installed build matrix covers English/Chinese defaults and both default-locale prefix modes. Historical skeleton upgrade matrices are not part of this release gate.
