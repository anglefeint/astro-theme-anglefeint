# 0.20.0 — Frontier navigation and cypherpunk reading cards

## Status

npm accepted publication from source commit `3148399` on 2026-10-20. Registry latest/download verification is pending; starter delivery and remote acceptance must wait for availability. The formal entry exhausted its bounded verification retries without republishing. Final delivery revisions will be recorded after verification.

## Changes

- Add an independent Frontier arrow beside the three primary navigation links. About remains a direct link. The dropdown contains Decoder Lab only, with keyboard/outside-click handling and theme-aware hover/focus styles.
- Add twelve illustrated external reading/resource cards below Decoder Lab, with a localized tribute, responsive grid and locally bundled optimized WebP covers. No essay full text is reproduced.
- Configure tribute and the complete uncapped list through `i18n.locales.<code>.messages.decoderPage.readings` in `src/site.config.ts`. Omitting configuration retains defaults; `links: []` hides cards; a supplied list replaces all defaults. Empty tribute text hides that text independently.
- Include `utm_source=anglefeint&utm_medium=referral&utm_campaign=decoder_lab` in twelve default URLs. Custom links remain as supplied, without automatic attribution. Existing noreferrer behavior remains; destination handling of UTM is not guaranteed.
- Correct Decoder Lab browser titles and reduce unused bottom spacing. Retain the existing animated peer network and reduced-motion behavior.

## Migration

Use the matching 0.20.0 starter, or deliberately update the Decoder route to pass locale and `messages.decoderPage.readings` to the package component. Updating npm alone cannot rewrite an existing project's route. Existing schema/message adapters already support the optional fields; no new adapter or alias is required. The existing Decoder switch hides its page and Frontier entry independently of About.
