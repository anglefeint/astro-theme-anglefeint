# 0.20.1 — Sixteen cypherpunk readings and eight-column layout

## Status

npm 0.20.1 and its matching public starter were delivered on 2026-10-22. Published package source: `d1b2274de1e84d75ecfc774a3a1b49e197848b9e`; starter: `6c836618652f9a590ec9156c160807baf79d18e9`, theme range `^0.20.1` and Vite `^8.3.5`. [GitHub Release](https://github.com/anglefeint/astro-theme-anglefeint/releases/tag/v0.20.1). Later documentation-only commits do not change the package source revision.

## Changes

- Expand default Decoder readings from twelve to sixteen: Satoshi Nakamoto’s November 6, 2008 P2P/freedom reply, Nick Szabo’s 1996 Smart Contracts essay, David Chaum’s 1985 Security without Identification and Wei Dai’s 1998 b-money.
- Add nine-language titles and four original, locally bundled cypherpunk WebP covers. The email is not presented as the whitepaper announcement; full source texts are linked externally, not reproduced.
- Render sixteen defaults in two rows at widths from 1440px, with eight columns and compact gutters/padding. Use four columns at 1101–1439px, two at 721–1100px and one below 721px. Keep readable title sizes and responsive lazy images.
- Preserve the existing configuration: omitted links use defaults, `links: []` hides cards, and custom lists replace all defaults. Sixteen default URLs include Anglefeint referral UTM; configured URLs are not decorated automatically.
- Refresh main/starter Vite to `^8.3.5` after the blocking audit flagged locked 8.3.2. Official advisories identify 8.3.3 as the patched 8.3-series floor; 8.3.5 stays in the same patch series. No forced audit fix or vulnerability exemption is used.

## Migration

Compatible package update for matching 0.20.0 starters. No route, schema, adapter or manifest contract changes. Rebuild and redeploy. Starter sync updates package range/lockfile and managed public documentation/configuration comments.
