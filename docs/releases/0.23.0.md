# 0.23.0 — About navigation and smaller lossless OG images

## Status

Published npm `@anglefeint/astro-theme@0.23.0`. Exact package source: `c93e130615eef287c1c728a415f03c2527c9a269`. Public starter: `ab9dde6e9eaef1d04a987a5cb115e7b85ab64ac8`, using `^0.23.0` with lockfile version 0.23.0. Final GitHub references are recorded in the Release body.

## Changes and ownership

About gains a five-section localized directory with native anchors (`who`, `what`, `ethos`, `now`, `contact`). From 1360px, the directory sits 1.2rem beyond the centered reading panel’s right edge, with bounded scrolling on short viewports; narrower layouts wrap inside the panel. DL Data, AI, Decryptor and the other tool shortcuts remain in their original independent sidebar. Section headings use semibold system sans-serif with restrained tracking and warm-gold accents; Contact and its links are more prominent. Contact heading/copy render immediately rather than waiting for title typing. No new downloaded font is introduced.

The Frontier dropdown gains a localized About Contact anchor, independently gated from Decoder Lab. Choosing a link closes the menu; outside click and Escape dismissal remain supported, with Escape restoring trigger focus. No scroll-spy or animation loop is added.

Package-owned AboutContents and FrontierMenu own their presentation. CommonHeader owns locale/feature decisions; the About route supplies localized heading data. Shared section IDs and the Contact anchor live in `utils/about-sections.ts`; the panel and directory use one width token. Typography belongs in the panel layer, and title-animation opt-out uses a data attribute rather than a Contact ID dependency. The existing package directories/exports and starter-managed About route cover delivery; no new starter-owned destination is required.

Static OG PNG encoding now uses compression level 7 and adaptive filtering, without palette quantization, resizing or a font change. The measured 126-image average changed from approximately 815 KiB to 643 KiB (about 21% smaller; new range 616–670 KiB). A level-9 experiment saved little additional space at higher encoding cost; level 7 was retained. These are local image measurements, not a claim about network latency or all future content. Image cache-key version 3 ensures rebuilt references use the new files.

## Migration

Use the matching starter, or deliberately merge the updated project-owned About route and install the new package. The header can otherwise link to an absent `#contact` in a customized older route. Existing site/about configuration and translations remain valid. About and Decoder switches remain independent. Rebuild/deploy all output to refresh OG references. See [UPGRADING](../../UPGRADING.md#0230-about-navigation-and-lossless-og-images).

## Validation and privacy

Local main checks passed 138 unit tests, Lint, zero Astro diagnostics and 199 built pages with nine About payloads and 126 article exports. Three functional navigation tests cover nine-language directory/heading correspondence, separate tool ownership, native anchors without page JavaScript, Contact link activation, outside click and Escape/focus behavior. Screenshots/traces are disabled for these tests. Four social-image tests passed multilingual offline rendering, dimensions, credits, explicit-image preference and metadata-dependent URLs. A dev-toolbar heading initially caused an overly broad test locator to fail; it was scoped to the About article and the rerun passed. No appearance screenshot review was performed.

Main/isolated-starter/delivered-starter/public-template audits reported zero findings. The corrected formal invocation completed all default gates and the fourteen-build installed matrix. Registry latest and exact download verification passed; SHA-512 and all 260 tarball files matched the source revision. Fresh public-template acceptance passed install, CLI, checks, build/dev/preview and browser functionality, including nine-language About targets, independent tool ownership and removal of Contact when About is disabled while Decoder remains enabled. Live main verification passed nine languages, 126 articles, eighteen listing pages, older non-starter HTML/Markdown samples, About directory/header targets and new versioned 1200×630 OG samples (633,071–676,526 bytes across nine samples). No full dry-run precedes the formal publish entry and no existing check is removed. Evidence stays in ignored `acceptance-results/`, with redacted privacy summaries.
