# 0.24.0 — Archive views and cinematic interactions

## Status

Release preparation on main. Publication and delivery evidence will be recorded after the actual gates complete.

## Changes and ownership

Blog and tag archives gain connected Cards/List controls with a shared localStorage preference, nine neon palettes and a compact responsive grid. List mode provides continuous numbering, filtered totals, numeric dates and up to two independently clickable tags. Disabled storage and JavaScript retain usable article links. Diagonal cyan/magenta card frames retain the existing neon flicker; keyboard focus within a card strengthens its cover reflection without requiring pointer hover. Pagination also receives diagonal frames.

About contents gain diagonal frames and an amber runner with three seconds of travel and three seconds of rest, paused on hover/focus. Decoder reading cards gain mint/violet diagonal corners and staggered pulses. Reduced motion retains static feedback.

Home shows actual latest/total article counts, adds localized pointer feedback through the existing code-rain loop, green mirror-crack signals, compact article hover signals and a shared rabbit/ALL hit area. Door proximity hints do not activate or load the passage. Existing visibility, reduced-motion and cleanup ownership remains in place.

The package owns components, styles and effects. Four project routes supply archive offsets/totals and homepage totals. Two concise demo essays in nine languages explain AI-readable publishing and Decoder Lab's cypherpunk tribute; these additional demo posts are not distributed to starter consumers.

## Migration

Use the matching starter or merge the four project-owned routes described in [UPGRADING](../../UPGRADING.md#0240-archive-views-and-homepage-counts). Older callers remain renderable but cannot supply full-archive counts without the new props. No new schema, adapter, dependency or preference migration is required; static page size remains nine. Customized projects should merge deliberately rather than overwrite routes.

## Validation and delivery

Pending formal release checks, installed build matrix, blocking dependency audits, npm download/source verification, generated starter delivery, remote-template acceptance and live main inventory checks. No skipped gate is claimed as passing. Cloudflare account build settings have not been directly inspected; GitHub build checks and live inventory provide separate evidence and do not establish those settings.

The initial full browser run passed 118 scenarios and failed nine. Six timing/animation failures passed when rerun with one worker. The remaining tag tests exposed an actual Tags shortcut overlap with the fixed view control/header, plus stale selectors after the archive wrapper change and ambiguous case-insensitive matching of distinct tag labels. Archive CSS now reserves shortcut space and adds mobile header clearance; tests use exact tag destinations and the article-link class. Publication waits for the corrected source checks; no npm upload occurred during this recovery.
