# 0.24.1 — Complete desktop card rows

## Status

Release preparation; delivery results will be recorded after validation.

## Fix and migration

Change the default blog/tag page size from nine to ten in the project configuration defaults and package fallback. A full Cards page now contains one leading card and nine regular cards, filling three desktop rows. The final partial page still shows the remaining posts. List mode shares the same static pagination; visitor storage continues to save only the chosen view.

The matching starter includes the new default and updated guide examples. Existing projects should set `theme.blogPageSize: 10` in `src/site.config.ts` or merge the matching `src/site.config.defaults.ts`; a package update cannot overwrite an existing project default or explicit override. No schema, adapter or route changes are required. Rebuild and deploy the complete output to update page boundaries.

## Validation

The archive regression requires ten first-page entries, a complete three-column remainder and continuous second-page numbering. Formal release checks, installed matrix, audits, registry/source verification, starter and public-template acceptance remain pending.
