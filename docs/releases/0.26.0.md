# 0.26.0 — About reading window

## Status

Release preparation on main. npm publication, starter delivery and remote acceptance are pending; this record will be updated with actual delivery results.

## Changes

About moves the red/yellow/green controls to its outer title bar. Red closes the panel, removes its layout space and resets reading position; a warm amber About button appears at the bottom of the existing tools sidebar. Yellow hides an inert panel while retaining its layout space, document height and reading position, with a bottom-right restore dock. Header About navigation, native section links and terminal `open`, `close`, `minimize`, `maximize`, `restore` commands share the same controller. Controls and labels are localized; toolbar controls scroll normally with the document.

Green requests actual fullscreen on the About article, not the whole document. Only the reading panel is presented, with internal scrolling; green, Escape and native exit restore the original page position. Close/minimize exit owned fullscreen first. Rejected or unsupported requests leave the normal panel usable. Fullscreen is never automatically reentered after reload. Per-path versioned localStorage stores window/reading preferences with blocked-storage fallback; minimized content is inert and hidden from assistive technology. Without JavaScript the article remains readable and controls remain hidden.

The contents rail is 192px on desktop, omits its redundant visible title and retains an accessible name. It uses warm gray monospace links, rounded hover feedback, amber diagonal corners and the existing three-second orbit/three-second rest runner. Contact uses the ordinary text color/weight plus a soft halo and a six-second CRT line → centered oscilloscope waveform → both cycle. Reduced motion omits animated cues. The frame clips runner overflow, fixing the reproduced 11px horizontal-scrollbar issue without removing vertical access on short screens. Reading-panel and body padding are 16px; desktop controls are 16px with a 15px caption and larger touch targets.

## Upgrade

Use the matching 0.26.0 starter, or merge `src/pages/[lang]/about.astro` deliberately and install `@anglefeint/astro-theme@0.26.0`. The route must import/compose AboutWindowControls, identify `about-reading-window`, add the initially hidden sidebar opener and body-end restore dock, and remove the old OUTPUT dots. Installing the npm package alone cannot update a customized project-owned route. No new mandatory configuration, schema or adapter fields are required. See [Upgrading](../../UPGRADING.md#0260-about-reading-window); preserve customized content or migrate it into a fresh starter.

## Validation and delivery

Local source checks, lint/build and eleven About browser scenarios passed before release preparation. They cover distinct close/minimize recovery, stable minimized height/position across reload, header/Contact recovery, true panel fullscreen and independent scrolling, original-position restoration, rejection, command completion, storage denial, no-JavaScript reading and runner overflow. Functional tests do not replace installed-package and remote-template gates. No optional screenshot/appearance review was performed during release preparation; local visual decisions follow the user's feedback.

The formal publication entry retains its default main checks, main/isolated-starter audits and installed build matrix. The matrix additionally checks the actual controls/opener/dock markup, and tarball validation requires the new component, controller and CSS. The public-template acceptance browser check additionally exercises delivered close/minimize/fullscreen behavior. Actual publication and acceptance results will be recorded after completion.

Cloudflare dashboard branch controls and the active production revision have not been directly inspected; successful build checks alone will not be reported as verification of those settings. The live localized article inventory and changed About surfaces must be checked after the final branch push.
