# 0.27.1 — Isolated social-image build dependencies

## Status

Patch preparation following 0.27.0's remote Linux/pnpm failure. Publication and remote delivery are pending; no completed gate is claimed here until verified. Version 0.27.0 was accepted once, propagated and verified against its source; it is not republished or overwritten.

## Changes and upgrade

The social-image integration externalizes only its own build-only renderer to the original package-local file URL. Node resolves Satori/Yoga and Sharp from the package's own dependency context instead of a generated prerender chunk. This addresses Yoga CommonJS glue losing __dirname and Sharp becoming unresolvable in pnpm's isolated dependency graph. Other application imports are not intercepted. Render code, fonts, image templates, compression settings, browser effects, configuration and URLs are unchanged.

For schema-1 npm projects, run `npx @anglefeint/astro-theme@latest upgrade`, then preview and deploy normally. Existing pnpm projects update the theme deliberately using pnpm and run doctor; automatic npm conversion is still unsupported. No source/config/content/media migration is needed from 0.27.0. Pre-0.27 projects require the [breaking migration](../../UPGRADING.md#0270-integration-starter-breaking-not-yet-published).

## Validation and delivery evidence

A targeted resolver test checks the package-local external boundary, unrelated imports and preserved virtual configuration. Independent Windows/pnpm reproduction failed on 0.27.0 with Sharp resolution and passed doctor/build after installing the patched tarball. The original Linux/pnpm job failed with __dirname in bundled Yoga code. These are dependency-context failures, not visual changes.

The first Linux/npm 0.27.0 browser run passed 137/139: the animation assertion included automation click/poll transport (3518ms versus 3500ms), and an Oracle test exhausted its overall 30-second scenario timeout. The animation test now measures actual browser click-to-done (including decoding) with the same 3500ms bound. The Oracle scenario allows 60 seconds overall while retaining its individual forward/reverse deadlines and all interaction assertions. CI runs the complete suite with one worker; no retry or test exclusion is added. These test/workflow fixes do not alter runtime animation or effects.

Final main, installed matrix, browser, public registry/template/upgrade, Linux workflow and live verification results will be recorded after completion. Evidence lives under ignored acceptance-results/; initial pnpm reproduction is release-0271-pnpm-local.json, original Linux logs are release-0270-pnpm-linux.log and release-0270-npm-linux.log. No optional screenshot appearance review is claimed.
