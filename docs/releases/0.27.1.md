# 0.27.1 — Isolated social-image build dependencies

## Status

Published and recommended: `@anglefeint/astro-theme@0.27.1`, exact npm source `faa7c9e07aabcaf6fa0beefd0a9e6b1dc380781a`. This includes the [0.27.0 integration-starter architecture](0.27.0.md) and fixes its remote Linux/pnpm failure. Each version was uploaded once; registry propagation recovery only downloaded metadata/tarballs. The exact SHA-512, gitHead and all 307 package files were verified. Version 0.27.0 is superseded, not overwritten.

## Changes and upgrade

The social-image integration externalizes only its own build-only renderer to the original package-local file URL. Node resolves Satori/Yoga and Sharp from the package's own dependency context instead of a generated prerender chunk. This addresses Yoga CommonJS glue losing __dirname and Sharp becoming unresolvable in pnpm's isolated dependency graph. Other application imports are not intercepted. Render code, fonts, image templates, compression settings, browser effects, configuration and URLs are unchanged.

For schema-1 npm projects, run `npx @anglefeint/astro-theme@latest upgrade`, then preview and deploy normally. Existing pnpm projects update the theme deliberately using pnpm and run doctor; automatic npm conversion is still unsupported. No source/config/content/media migration is needed from 0.27.0. Pre-0.27 projects require the [breaking migration](../../UPGRADING.md#0270-integration-starter-breaking-not-yet-published).
