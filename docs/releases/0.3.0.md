# Release Notes: 0.3.0

## Changes

- Article contents generated from Markdown h2/h3 headings, with a wide-screen sidebar and collapsible inline contents on smaller screens.
- Pagefind full-text article search with localized dialogs, lazy loading, highlighted results and build-time indexing. Use build/preview for local search; dev mode explains the indexing requirement.
- Static per-language tag directories and paginated archives, article tag links, stable case-sensitive URLs, and a compact directory layout.
- Code-block copy buttons with localized success/failure feedback, keyboard access and fixed position during horizontal code scrolling.
- Unlinked article image previews with keyboard access, backdrop/Escape dismissal and reading-position restoration. Linked images preserve their destination.
- Reading-status notifications positioned outside the article's right border on wide screens; return-to-top placement avoids the contents panel.
- Removed the temporary public image test article and its three images. Image tests use browser-only generated fixtures.

## Starter and migration

This release requires the matching generated starter as well as the npm package. Search integration in `astro.config.mjs`, tag routes under `src/pages/[lang]/tags/`, and the article route's `headings` prop are project-owned. Updating npm alone does not create or rewrite these files.

Create a fresh project in a separate directory and migrate articles, assets and personal configuration deliberately. Keep the previous project until verified. Global configuration includes `theme.toc.enabled`, `theme.search.enabled` and `theme.tags.enabled`. Article `toc` overrides the contents default; `search: false` excludes an article from search; `tags` remains optional. Copy and image preview require no author markup or extra commands.

```bash
npm create astro@latest -- --template anglefeint/astro-theme-anglefeint#starter
```

The source archive attached to GitHub releases is the main workspace, not the generated starter template.

## Known limitations

Dependency security audit is not clean. On the release date, `npm audit` reported 16 advisories in the installed starter (1 low, 2 moderate, 12 high, 1 critical) and 29 in the maintainer workspace (1 low, 7 moderate, 20 high, 1 critical). The starter resolved Astro 6.1.3 and Sharp 0.34.5; direct dependency findings include Astro, Sharp and `@astrojs/rss`. The critical Astro finding is [GHSA-26w7-cxv4-gfx2](https://github.com/advisories/GHSA-26w7-cxv4-gfx2), concerning AVIF image optimization. These findings were not remediated by this feature release; a dependency upgrade and compatibility/security review remains outstanding. Passing functional tests does not establish that these advisories are harmless.

Runtime acceptance used Windows, Node 24.14.1, npm and Chromium. Other browsers, package managers and SSR deployments were not validated in this release. Build output retains an upstream unused-import warning from Astro's remote image helpers.
