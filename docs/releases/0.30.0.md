# 0.30.0 — Reusable effects and Fragments

## Delivery status

npm `@anglefeint/astro-theme@0.30.0` is published from exact source `81463f0380c273b3d06c32aec24f9c0a834ddc78`. Official starter `af777f0486bc37de48b2ba6fe00d6cd0022f7160` is delivered with ^0.30.0 and an exact 0.30.0 lockfile. Windows public-template, published upgrade and final live acceptance passed. Linux npm acceptance and GitHub announcement closeout are still pending.

## Changes

- Extract fourteen self-contained visual groups into the existing theme package's `effects/` directory, with explicit elements, lifecycle controls and optional text configuration. Standard pages use small scene adapters; existing timing, viewport behavior and shared Matrix/mirror frame flow remain. Mirror and corridor implementations are unchanged. No UI library, animation dependency or independent package is added. See the [API and ownership reference](../REUSABLE_EFFECTS.md).
- Improve fragment comment loading with a Cyberpunk signal, static reduced-motion fallback, compact loading dimensions and a fixed dialog header/close control. Retained iframe sizing no longer causes loading scrollbars; long ready-state comments scroll inside the body. Articles and fragments keep the same official Giscus integration, repository settings and their existing discussion mappings.
- Compact Fragments typography/card spacing and place the localized subtitle beside a static cool-gray/teal segmented title. Distinguish the FRONTIER Contact shortcut from the active route.
- Enable article/fragment comments in the public demo and add twelve translated example fragments per language across all nine languages, retaining shared stable IDs/dates. Personal blog defaults stay off; demo examples are not distributed to starter.
- Clarify existing Astro 7 requirements in all nine README translations. No Astro dependency upgrade or JSON logging/background-service integration is included.

## Upgrade

For npm schema-1 integration starters:

```sh
npx @anglefeint/astro-theme@latest upgrade
```

Use `--to 0.30.0` to target this version. Preview and deploy after success. No configuration/content migration or new script is required. User configuration, Markdown, media, custom pages and fragment IDs remain user-owned; no GitHub discussions are merged, moved or deleted. Package/starter Fragments and comments remain opt-in. Pre-0.27 copied skeletons require the [fresh-starter migration](../../UPGRADING.md#0270-integration-starter-breaking-not-yet-published).

New blog:

```sh
npm create astro@latest -- my-blog --template anglefeint/astro-theme-anglefeint#starter --no-install --no-ai
cd my-blog
npm install
npm run dev
```

GitHub source archives contain main maintainer source, not the generated personal-blog starter.
