## Changes

- `new-fragment` defaults to every enabled project language, matching `new-post`. All files from one invocation share one UUID, timestamp and filename, with no automatic translation. Disabled languages are excluded from default generation; the configured default language remains included.
- Both commands share `scaffold/shared.mjs#resolveLocales`, using `--locales` → `ANGLEFEINT_LOCALES` → configured languages. Explicit lists trim whitespace, lowercase codes, deduplicate and validate syntax before writing. Overrides bypass configuration loading and create only requested locale directories; they do not enable routes or change site configuration. The old `new-post.mjs` export is preserved.
- Keep exclusive-write skeleton creation and original file protection. Existing fragments/IDs, comments, publishing defaults, routes and visual effects are unchanged.
- Synchronize all nine README translations and demo/starter User Guide 5 pairs, including the new default, explicit single/multiple-language examples and version boundary. Update architecture, upgrade guidance and installed/public-template/upgrade acceptance.

## Upgrade

For npm schema-1 integration starters:

```sh
npx @anglefeint/astro-theme@latest upgrade
```

Use `--to 0.31.0` to target this version. No configuration/content migration is required. To retain the old single-language result, add the desired language:

```sh
npm run new-fragment -- --locales zh
# Existing projects without a new-fragment script:
npx @anglefeint/astro-theme@latest new-fragment --locales zh
```

Automatic upgrades change dependencies, not personal articles/fragments/configuration/media or tutorial copies. Existing IDs/comment associations stay intact. Feed/comment defaults remain off for personal blogs. Versions 0.29–0.30 default to one language; default all-enabled-language generation requires 0.31.0. Pre-0.27 copied skeletons need the [fresh-starter migration](../../UPGRADING.md#0270-integration-starter-breaking-not-yet-published).

New blog:

```sh
npm create astro@latest -- my-blog --template anglefeint/astro-theme-anglefeint#starter --no-install --no-ai
cd my-blog
npm install
npm run dev
```

GitHub source archives contain maintainer main source; use the public starter command for personal blogs.
