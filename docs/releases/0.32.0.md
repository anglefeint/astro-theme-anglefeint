Official starter `1ecfcd51cde5ec25721cdc5d0b96b180973c674e` is delivered with ^0.32.0 and an exact 0.32.0 lockfile. Public npm/pnpm templates, real published upgrade and production acceptance passed. Tag/announcement closeout uses `v0.32.0` at that exact npm source; the [GitHub Release](https://github.com/anglefeint/astro-theme-anglefeint/releases/tag/v0.32.0) records the final main closeout reference.

## Changes

- Date links and adjacent copy controls share `/<locale>/fragments/#fragment-ID`. Ordinary clicks locate the existing card within its list; there are no Fragment detail pages. Denied clipboard access reveals a selectable link.
- Each language receives a content-versioned static ID→page JSON index generated by the same sorting/pagination helper as its feed. Current-page hits do not request it; absent targets load it on demand. Missing IDs, network errors, stale replies and mixed-cache destinations have localized feedback and one-hop loop protection. Indexes contain no Markdown and are excluded from the sitemap.
- Fragments reuses Blog/tag `CyberPagination`, its neon styles, ellipses and threshold-based jump controls through existing `theme.pagination` settings. `theme.fragments.pageSize` remains independent.
- Cards share Blog's cyan/magenta cut-corner frame. Comment controls use a nearly transparent blue-gray outline with two small cuts and cyan hover/focus feedback. Dates highlight without underlines, and heading/card separation is slightly larger. Existing card density, comments and reduced-motion behavior remain.
- Synchronize nine READMEs and nine demo/starter Guide 5 pairs, plus upgrade/architecture/visual/acceptance references. Public-template checks exercise the actual installed index, stable cross-page link and shared pagination.

## Upgrade

For supported npm schema-1 projects:

```sh
npx @anglefeint/astro-theme@latest upgrade
# Select this exact version:
npx @anglefeint/astro-theme@latest upgrade --to 0.32.0
```

Preview and redeploy after success. Keep Fragment frontmatter IDs stable; rebuild after additions, date changes or page-size changes. JavaScript is required for automatic cross-page locating/copying. Removed numbered URLs still use ordinary hosting 404 behavior; share the stable root URL instead. Existing Giscus terms remain `fragment/<id>` and discussions are not moved/deleted. Personal content/config/media are preserved, and upgrades do not overwrite tutorial copies. Feed/comments default off for personal blogs; demo comments remain on. The local five-item review configuration is not shipped, and default page size stays 20. See [upgrade guidance](../../UPGRADING.md) for the pre-0.27 migration boundary.

New blog:

```sh
npm create astro@latest -- my-blog --template anglefeint/astro-theme-anglefeint#starter --no-install --no-ai
cd my-blog
npm install
npm run dev
```

GitHub source archives contain maintainer main source; use the starter command for personal blogs.
