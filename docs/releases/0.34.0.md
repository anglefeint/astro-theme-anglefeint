# 0.34.0 — About and Fragments machine-readable content

Status at source preparation: not yet published. The [GitHub Release](https://github.com/anglefeint/astro-theme-anglefeint/releases/tag/v0.34.0) records observed npm/source/starter/tag identities, final technical results and per-stage/end-to-end release timings after authorized delivery. This source note does not claim upload success before it happens.

## Changes and migration

- Articles retain existing Markdown URLs. Enabled public About and Fragments join language llms indexes and full-text bundles. About exports biography/contact and its reachable public AI text popup, excluding terminal/tool/configuration dumps and comments.
- Each language has an About companion and a single Fragments companion combining public pagination. Notes retain ID/time/body and stable original #ID sharing links. All supported HTML pages advertise their companion and language index; no Fragment detail route, ID/comment migration, new runtime script or UI dependency.
- Unified owner-manifest cleanup removes stale generated companions/indexes/bundles and discovery links after deletion, feature/language disabling or noindex changes. Conflicts with user-authored files stop builds; noindex/off-site canonical content is excluded, and pagination cannot bypass a missing/noindex feed root.
- Site/article JSON-LD gains configured language, and About emits AboutPage with language. Nine-language README, npm README and nine pairs each of demo/starter Guides 1/3/5 are synchronized. No new configuration/server/AI service is required. Follow the normal supported schema-1 npm upgrade and redeploy; personal tutorials remain user-owned. No AI indexing/citation outcome is guaranteed.

## Technical evidence and release selection

Implementation iteration: 14 focused unit cases plus one real nine-language paginated/About static-render case passed. Astro: 0 errors, 0 warnings, 1 existing hint; lint, metadata (101 documents), formatting and relevant links passed. All 27 demo/starter tutorial pairs agree and 63 tutorial route links resolve in built output. The isolated template build took 30.06s; current-project build took 31.50s and exported 162 articles, 117 Fragments and 9 About pages, with 1570ms in the exporter. Initial implementation/documentation/validation elapsed 9m30s; this is separate from the release timing below.

The release selects quick relevant machine/head/verifier unit files, current release documentation checks, and one independently installed default build. npm delivery retains registry/version, blocking audit, pack, identity, one upload and source/metadata/download verification. Starter delivery retains install/audit/doctor/build and main dependency restoration. No full source aggregate, fourteen-case matrix, browser, Cloudflare or live-demo acceptance is selected. Demo regression belongs to the user. No historical-result cache is used; unchanged implementation checks are recorded as earlier evidence rather than claimed as rerun.

Normal and recovery verification now share strict tag/exact metadata/source/downloaded-hash checks. Each failure persists its stage/code/redacted reason/action. Only named transient failures retry within unchanged 12-attempt/10-second/15-second-fetch bounds; identity/authentication/malformed/unknown failures stop immediately. An accepted upload is never repeated.
