# 0.37.2: Share images for static Home redirects

## Fix

Both default-language Home redirect pages now include Open Graph and large-image Twitter Card metadata in their static HTML. This covers `/` redirecting to a prefixed Home, and the localized default Home redirecting to `/` when the prefix is disabled. Crawlers can read the sharing information without following the HTML refresh.

The lightweight shared head uses the site title, the destination Home's localized description, and the existing `site.ogImage` public-path/HTTPS resolution or bundled 1200×630 fallback. Public-file revisions are retained. Canonical and social URLs identify the destination Home; meta-refresh, `noindex, follow`, route addresses and visual effects stay unchanged. Hosting rules and server rendering are not added. Sharing platforms still determine whether and when to refresh or display a preview.

## Compatibility and starter delivery

No new configuration, dependency, schema or content migration is required from 0.37.1. Astro peer support remains `^7.4.7`; the main/starter target remains `^7.4.12`. Upgrade the theme, rebuild and redeploy to deliver the corrected HTML. User content, configuration, media and custom pages remain user-owned.

Starter synchronization updates the dependency range/lock and delivers the previously corrected consumer `AGENTS.md` Fragment instructions: default creation covers all enabled languages; files created together share an ID and timestamp and are not automatically translated. No empty package release is being made for that documentation change; the Home redirect runtime fix requires this patch.

## Selected validation and delivery plan

Run the focused static-render test for both Home prefix modes, including default/custom share images and comparison with destination metadata; Astro types; one main build; one independent installed-package check; lint, formatting and documentation metadata. Retain blocking dependency audits, packing, normal commit hooks, exact npm download/source verification, and isolated starter install/doctor/build delivery. No browser, screenshots, live Giscus or hosting acceptance is selected.

Final source/npm/starter identities, completed checks and timings belong in the [GitHub Release](https://github.com/anglefeint/astro-theme-anglefeint/releases/tag/v0.37.2) and ignored session evidence. This plan does not claim delivery before execution.
