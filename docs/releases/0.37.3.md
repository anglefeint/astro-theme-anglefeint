# 0.37.3: Frontier navigation highlights and shared colors

## Changes

Decoder Lab and Fragments now keep the Frontier menu arrow and bottom marker highlighted while their existing menu link is active. Decoder uses the Decode button's mint `#8ee8c3`; Fragments uses Protoss-inspired crystal blue `#6ed4ff`. The active item uses the same color, including on paginated Fragments. Other navigation items, routes and menu behavior remain unchanged; no animation is added.

The shared neon pool grows from nine to eleven complete palettes. Variants 1–9 retain their colors; variant 10 / `neon-decoder` uses `--neon-decoder-mint`, and variant 11 / `neon-protoss` uses `--neon-protoss-cyan`. Components sampling the shared count can select the new colors. Pagination continues to respect its configured variant count, whose default remains 9; set it to 11 to include both additions. Variant 12 still has no independent palette.

Nine-language configuration references and matching starter templates now describe the complete 1–11 range and unchanged defaults. Existing user copies are not overwritten by theme upgrades.

## Compatibility and starter delivery

No configuration, dependency, schema or content migration is required from 0.37.2. Astro peer support remains `^7.4.7`, with main/starter target `^7.4.12`. Upgrade the theme, rebuild and redeploy. User content, personal settings, media and custom pages remain user-owned. Starter delivery updates its dependency/lock and the localized reference copies.

## Selected validation and delivery plan

Run the focused visual-variant unit file for random/fixed/sequential behavior and complete palette tokens, Astro types, one main build, one independent installed-package check, lint, formatting and documentation metadata. Retain virtual starter checks, blocking main/installed/starter audits, packing, normal commit hooks, exact npm source/download verification and isolated starter doctor/build. Local visual iteration was reviewed by the user; this release does not run a browser suite, screenshots, live Giscus or hosting acceptance.

Final source/npm/starter identities, completed checks and timings belong in the [GitHub Release](https://github.com/anglefeint/astro-theme-anglefeint/releases/tag/v0.37.3) and ignored session evidence. This plan does not claim delivery before execution.
