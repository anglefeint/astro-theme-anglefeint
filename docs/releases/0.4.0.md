# Release Notes: 0.4.0

## Changes and security

- Upgrade to Astro 7.3.2 and Sharp 0.35.4, addressing the AVIF image-processing advisory [GHSA-26w7-cxv4-gfx2](https://github.com/withastro/astro/security/advisories/GHSA-26w7-cxv4-gfx2). Update MDX, RSS, sitemap, checking/deployment tools and affected transitive dependencies.
- Require Astro `^7.3.2` in the theme peer dependency. This is a breaking compatibility change from the previous Astro 5/6 range.
- Preserve HTML whitespace with `compressHTML: true` and adapt the Playwright preview process lifecycle for Astro 7.
- Tag directories and tag archives share rain/dust with the blog list, retaining spotlight and flicker with softer ice-blue/lavender colors, slower sweeps and a static reduced-motion background.
- Reconcile documentation with implemented search, contents, tags, copy, image preview, routing, configuration and distribution boundaries.
- Make main and isolated-starter audits blocking in npm releases, including `--skip-checks`; starter sync audits before committing. GitHub Release creation and read-back are explicit completion requirements.

## Migration

Use the matching current starter in a new directory and migrate content/configuration following [UPGRADING](../../UPGRADING.md). Updating the npm theme alone does not upgrade Astro/Sharp, add the shared atmosphere component, or rewrite routes/configuration. Do not keep the old Astro 6 lockfile or bypass peer dependency errors.

```bash
npm create astro@latest -- --template anglefeint/astro-theme-anglefeint#starter
```

Existing 0.3.0 installations need deliberate dependency migration; publishing this release does not patch those projects automatically. The GitHub source archive is main source, not the generated starter.

## Validation and delivery

Release preparation is in progress. Final source/starter commits, registry verification, remote-template acceptance and GitHub closeout will be recorded after those actions succeed.

Local security-upgrade validation passed: main and isolated installed starter audits reported zero known vulnerabilities; 46 unit/integration tests, 24 browser tests, main checks/lint/build and the independent starter build matrix passed. A benign AVIF decode/resize/PNG conversion passed with Sharp 0.35.4 and libheif 1.23.2. These results are version/functional checks, not exploit reproduction or a guarantee against unknown vulnerabilities. Release-preparation checks will be rerun on the committed source.
