# Release Notes: 0.5.1

## Changes

- Default the Chinese language menu option to `简体中文` in starter configuration and the package fallback.
- Keep user-defined `i18n.locales.zh.meta.label` overrides. Language routes, content directories and SEO locale metadata are unchanged.
- Explain display-name customization in the user config example, five READMEs and architecture documentation.

## Migration

Compatible with the 0.5.0 project skeleton. Updating the npm package does not overwrite existing starter configuration. Existing users may keep their current label or merge this optional setting into their existing `defineThemeConfig()` object in `src/site.config.ts`:

```ts
i18n: {
  locales: {
    zh: {
      meta: {
        label: '简体中文';
      }
    }
  }
}
```

The latest starter includes the new default:

```bash
npm create astro@latest -- --template anglefeint/astro-theme-anglefeint#starter
```

GitHub source archives contain main source, not the generated starter template.

## Limitations

The change is a display label only. It does not add Traditional Chinese translation or new locale routes. Package-manager acceptance uses npm.

Desktop/mobile visual inspection was not completed because the browser tool was blocked on a prior connection-error page. No CSS or layout was changed; the validation above covers configuration, rendered HTML and HTTP behavior rather than a visual sign-off.
