# Release Notes: 0.6.0

## Changes

- Matrix: pale luminous rain heads and varied column speed/trail length, reusing the existing canvas and frame limits.
- Cyberpunk: blue/pink reflected light on card covers, stronger on hover/focus. Original rain, spotlight and flicker parameters are preserved.
- AI: up to six signal paths on the existing network graph, with arrival rings and no added canvas or animation loop.
- Hacker: a 360ms decorative title decode when opening a tool, with stable accessible names and localized grapheme handling. Closing/reopening cancels the previous timer. Reduced motion skips decoding and window-edge animation.
- About reading status: on screens at least 1360px wide, the toast sits 12px outside the content panel's right edge and 1rem above the viewport bottom. Narrow screens keep the corner position.
- Document lightweight, simple publishing and four vivid cinematic atmospheres as core product identity. The earlier experiment reducing rain/spotlights and changing home text/panel styling was reverted and is not included.

## Migration

Compatible with the current 0.5.x starter. The visual changes are package-owned; no configuration, route or content-schema migration is required. Install `@anglefeint/astro-theme@^0.6.0` explicitly: `npm update` within `^0.5.1` does not cross the 0.x minor-version boundary. Then check/build your site. The starter also replaces the About page's HTML escape regular expressions with equivalent literal `replaceAll` calls for compatibility with the new Astro language checker. New installations use:

```bash
npm create astro@latest -- --template anglefeint/astro-theme-anglefeint#starter
```

Starter synchronization is required to deliver the new package range/lockfile and managed documentation. GitHub source archives contain main source, not the generated starter template.

## Limitations

Desktop/mobile Chromium checks establish functional behavior, not low-end device GPU/frame-rate or battery performance. No new dependencies were added. The five initial effect files increased by approximately 1.3 KB when individually gzip-compressing their source; this is not a production bundle measurement and predates the About toast placement change.
