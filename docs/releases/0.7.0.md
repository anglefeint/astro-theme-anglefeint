# Release Notes: 0.7.0

## Changes

- Optional music player, off by default and hidden for empty playlists. No audio files or new dependencies are shipped.
- Independent native Audio core, session persistence and scoped presentation. Play creates the audio source; pause/resume reuses it. Track changes discard stale events and failed play promises cannot corrupt later playback.
- Luminous teal/blue glass panel, breathing LEDs (reduced-motion aware), progress seeking, previous/play/next, playlist, mute and volume controls. Device captions remain English; accessible names and playback feedback follow the five-language registry.
- Lower-left placement separates music from article controls. At widths up to 720px, pages start compact, reserve space for return-to-top, and hide that button only while music is expanded. Desktop collapse preference is remembered within the tab session.
- Configure `theme.music.enabled` and `tracks` in `src/site.config.ts`. Each track requires `title` and a public-path or HTTPS `src`; `artist` is optional. Public paths respect Astro's base URL.

## Migration

The matching starter schema, defaults and generated theme adapter are required to configure music. npm alone does not replace those files. Create a fresh starter and migrate content and personal settings as described in [UPGRADING](../../UPGRADING.md). No bundled demonstration music remains. A `^0.6.0` dependency range does not include 0.7.0.

```bash
npm create astro@latest -- --template anglefeint/astro-theme-anglefeint#starter
```

Navigation pauses playback; users click Play to resume the remembered track and position. This release does not add seamless cross-page playback or a router. GitHub source archives contain main source, not the generated starter template.
