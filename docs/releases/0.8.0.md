# 0.8.0 — Footer credits and demo identity

The shared footer displays `© <build year> <site title> · Theme by Anglefeint · Built with Astro`, with links to the theme repository and Astro. `theme.footer.showCredits: false` removes both technical credits; copyright and custom `site.tagline` remain. The new tagline default is empty; the former default `Built with Astro.` is treated as the built-in credit to avoid duplication. No all-rights-reserved notice or new browser script is added.

The demo has five-language homepage/About copy and its own identity. Starter sync and drift detection now use a neutral configuration source template for `src/site.config.ts`, also used by isolated installation checks. The demo domain/author/introduction are not distributed to starter users. About omits the email link when no email is configured.

## Migration

Use the matching starter schema/defaults and generated theme adapter to configure the credits switch. npm alone cannot replace them. A `^0.7.0` range does not include 0.8.0; follow [UPGRADING](../../UPGRADING.md), create a fresh template and migrate content and personal settings without replacing its helpers. Five-language User Guide 3 includes the configuration and behavior.

```bash
npm create astro@latest -- --template anglefeint/astro-theme-anglefeint#starter
```

GitHub source archives contain main/demo source, not the generated starter.

## Validation and delivery

Local verification passed: 56 unit tests, Astro diagnostics (zero errors/warnings), lint, documentation metadata, 30 Chromium tests, and the independent installed-starter build/audit matrix. Footer checks cover enabled/disabled links, retained custom tagline and desktop/mobile output in five locales. Neutral configuration mapping is checked during independent installation. The former email-only smoke assertion was updated to accept the demo's actual GitHub contact link.
