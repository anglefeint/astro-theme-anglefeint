# 0.8.1 — Music session resume

## Changes

Active music sessions now attempt to resume at their saved position after ordinary page navigation, reload and browser-history restoration. Manual pause remains paused. First visits do not autoplay. Browser policy denial shows a localized click-to-continue message rather than a broken-audio error; it cancels automatic retry while preserving manual recovery. Removed tracks never autoplay a replacement. Page departures preserve resume intent before suspending playback; restored cached pages reconcile the latest tab session.

This is resume after a document load, not seamless playback. There may be a short interruption, and browser policy can require a click. No ClientRouter, page-effect changes, new dependency, configuration field or bundled song is introduced.

## Upgrade

Compatible package-only update for the matching 0.8.0 starter and its Astro range. Run `npm update @anglefeint/astro-theme`, then `npm run doctor`. No adapter/config migration is required. Existing session records default to paused until the user plays. Older starters must satisfy the baseline in UPGRADING; installing this package does not migrate their local skeleton.

Starter synchronization delivers the package range/lockfile and updated five-language README/User Guide 3. The package owns all playback runtime changes and five-language feedback.
