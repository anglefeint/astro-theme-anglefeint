# 0.8.2 — Music scrollbar color isolation

The music deck and playlist now explicitly use thin teal scrollbars with transparent tracks. They no longer inherit the article page's pink or About page's gray scrollbar colors. Scoped WebKit rules provide a fallback for older browsers. Page scrollbars, player layout, playback behavior and configuration are unchanged.

## Upgrade

Compatible package-only patch for matching 0.8.0/0.8.1 starter projects. Run `npm update @anglefeint/astro-theme`, then `npm run doctor`. No configuration, route or adapter migration is needed. Older starters must meet the baseline requirements in UPGRADING. Starter synchronization updates its package range and lockfile.

## Validation and delivery

- The implementation turn passed lint, 58 unit tests, Astro checks and a complete build. Chromium computed-style checks verified both overflowing player containers use teal under home/list/article/About body classes; the article page's own pink scrollbar remains unchanged. Older WebKit/Firefox scrollbar rendering was not independently tested.
- This release will run the publish dry-run, dependency audit and isolated installed-starter checks before publication. Final source/starter commits, registry verification and public-template acceptance will be recorded after delivery.

Create a new user site with:

```bash
npm create astro@latest -- --template anglefeint/astro-theme-anglefeint#starter
```

GitHub source archives contain main source, not the generated starter template.
