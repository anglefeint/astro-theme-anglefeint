# 0.8.2 — Music scrollbar color isolation

The music deck and playlist now explicitly use thin teal scrollbars with transparent tracks. They no longer inherit the article page's pink or About page's gray scrollbar colors. Scoped WebKit rules provide a fallback for older browsers. Page scrollbars, player layout, playback behavior and configuration are unchanged.

## Upgrade

Compatible package-only patch for matching 0.8.0/0.8.1 starter projects. Run `npm update @anglefeint/astro-theme`, then `npm run doctor`. No configuration, route or adapter migration is needed. Older starters must meet the baseline requirements in UPGRADING. Starter synchronization updates its package range and lockfile.

## Validation and delivery
