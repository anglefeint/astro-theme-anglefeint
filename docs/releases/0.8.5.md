# 0.8.5 — Automatic article translation metadata

The theme now discovers actual same-slug translations for standard article routes inside `BlogPost`. Existing standard 0.8.3/0.8.4 starters can update the npm package, rebuild and deploy without editing routes, configuration or frontmatter. Existing explicit `seoLocaleHrefs` mappings remain valid and take precedence, including empty maps. Version 0.8.4 remains published.

## Upgrade

On compatible Astro `^7.3.2` starters, run `npm update @anglefeint/astro-theme`, confirm the installed version with `npm ls @anglefeint/astro-theme`, then run `npm run doctor` and deploy the rebuilt site. Standard URLs use `/<locale>/blog/<slug>/`; nested and Unicode slugs are supported. Unknown custom routes omit automatic alternates; custom route owners may pass an explicit mapping. Menu fallbacks and canonical URLs remain unchanged. No new dependencies are added.

New projects use:

```bash
npm create astro@latest -- --template anglefeint/astro-theme-anglefeint#starter
```
