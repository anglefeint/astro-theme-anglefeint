# 0.9.0 — Nine built-in languages

## Status

Published npm `@anglefeint/astro-theme@0.9.0` and delivered the matching public starter on 2026-10-03–04. New installations enable nine languages by default.

- npm source / `v0.9.0` target: `832d225ba1eaf9ef55a87af46bb743431dccd20d`.
- Delivered starter: `2a0fa1fd316175a62a9e3ff9f7bd7ff04d040c44`.
- Downloaded npm tarball SHA-1: `1013a542cb65094bc61f85de716a7c1929cda831`, matching the locally packed and published artifact.

```bash
npm create astro@latest -- --template anglefeint/astro-theme-anglefeint#starter
```

Compatible dependencies were refreshed to Astro 7.3.5, MDX 8.0.2, Sharp 0.35.5 and Vite 8.3.2, plus compatible tooling/transitive updates. Fixable braces/devalue advisories are resolved. Raw npm audit still reports the upstream cache advisory through Astro (3 entries in main; an installed theme can add a fourth ancestor). It is not fixed upstream.

On 2026-10-03 the maintainer authorized release after an impact review. The reviewed Astro caller only computes remote-image cache lifetimes, does not call the vulnerable cache-reuse method, and the template deploys static output. A narrowly scoped, expiring release exception verifies the exact advisory, installed versions and reviewed source/config fingerprints; other findings and audit errors still block release. See [the audit review](../PACKAGE_RELEASE.md#temporary-static-cache-advisory-review-2026-10-03). No forced downgrade, dependency override or node_modules patch was used.

## Changes

- Add Brazilian Portuguese (`pt-br`), German (`de`), Russian (`ru`) and Traditional Chinese (`zh-hant`) alongside the original five defaults. English remains the default; existing route keys remain unchanged.
- Supply complete message dictionaries, new-post skeletons, localized neutral About content, demo introductions, four README translations and fourteen translated demo articles per new language. The generated starter selects four articles per language, for 36 files; main has 126 articles.
- Use `pt-BR` / `zh-Hant` HTML and hreflang tags; retain lowercase route keys. HTML language now follows configured hreflang, including `zh-CN` for the existing `zh` route. Search indexes remain separated by page language.
- Map automatic Giscus language to `pt` and `zh-TW` for the new regional/script locales. Explicit comment-language configuration still takes priority.
- Keep horizontal LTR layout. Adapt narrow article panels and long text; prevent hidden link-preview boxes from widening the page. Signature visual effects are retained.
- Add translation-schema/placeholder coverage, locale configuration tests, new article inventory checks, share-image cases and browser tests for the four new locales.

## Migration

This upgrade requires matching starter configuration/content/docs as well as the package. An npm-only update provides package UI strings and scaffolds, but does not add languages to an existing starter's local registry or translate its content.

Create the latest public starter in a new directory and migrate personal content/settings deliberately. Do not overwrite customized files or copy old configuration helpers over the new ones. All nine languages are initially enabled: disable unwanted languages with `meta.enabled: false`. Omitted overrides do not disable defaults, and the default locale remains enabled. The new-post command creates nine skeletons initially; it does not translate content. Existing article files are preserved.
