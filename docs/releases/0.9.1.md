# 0.9.1 — Music follows the page atmosphere

Published npm `@anglefeint/astro-theme@0.9.1` and delivered the matching public starter on 2026-10-04.

- npm source / `v0.9.1` target: `070249615f61250bc04b27c3fb4698f2390681b8`.
- Delivered starter: `2e6f57007163543539d7ae8d76141dae405da1e3`.
- Downloaded npm tarball SHA-1: `b19f3450aeec1c3e9b06552cf1c57ee508a557ed`, matching the preparation/published package.
- [GitHub Release](https://github.com/anglefeint/astro-theme-anglefeint/releases/tag/v0.9.1). The tag identifies the npm source; documentation closeout follows on main.

```bash
npm create astro@latest -- --template anglefeint/astro-theme-anglefeint#starter
```

## Changes

- Inherit the shell's CSS colors for the music panel, controls, selected tracks, progress and scrollbars: Matrix green, Cyberpunk pink/ice blue, AI ice blue/pink and Hacker green/neutral text.
- Match About's terminal with black surfaces, neutral borders, compact corners and monospace controls, including playlist buttons. Keep green playback/status accents and LED animation.
- Isolate music title and secondary text from Home's broad paragraph styling. Preserve playback, session resume, default-off settings and mobile controls.
- Extend the isolated Chromium music fixture to check all four real shell styles, live token inheritance, About framing and mobile bounds.

## Upgrade

Compatible package-only patch for the matching 0.9.0 starter. Run `npm update @anglefeint/astro-theme` and `npm run doctor`, then preview. No route edits, new configuration, generated adapters or content migration are required. Older starters retain their existing compatibility requirements in UPGRADING.md.

Starter synchronization updates the distributed package range and lockfile for new users. No audio files are shipped and music remains disabled by default.
