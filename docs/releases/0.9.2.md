## Changes

- Add an offline, package-bundled background with green code rain, floating terminals and a cyan/pink network core to automatically generated 1200×630 article share cards.
- Keep the site's own title, article title and author as generated text. Protect wrapped titles with a localized dark gradient; keep the illustration vivid below the reading area.
- Add a small `Theme by Anglefeint` label at the bottom right, controlled by the existing `theme.footer.showCredits` setting. False hides both footer credits and this image label. No new configuration field.
- Include credit visibility and a new template version in generated image hashes. Preserve explicit `ogImage`, disabled generation and hero fallback behavior.
- Bundle an approximately 91 KiB background with no external image service, browser JavaScript or new dependency.
- Synchronize all nine README and content-guide translations.

## Upgrade

Package-only patch for matching 0.9.0/0.9.1 starters:

```bash
npm update @anglefeint/astro-theme
npm run doctor
npm run preview
```

Rebuild and redeploy after upgrading or changing credit visibility. No route edits, new frontmatter, adapter regeneration or content migration are required. User-provided `ogImage` files are never modified. Social platforms can retain cached previews until they fetch the page again.

Starter synchronization supplies the updated package range, lockfile and documentation for new installations. Older starter compatibility requirements remain in UPGRADING.md.

```bash
npm create astro@latest -- my-blog --template anglefeint/astro-theme-anglefeint#starter --no-install
```
