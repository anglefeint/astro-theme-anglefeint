初回公開は[配備ガイド](/ja/blog/starter-guide-deployment/)の ID 取得・公開テキストを、設定ファイルは[インストール](/ja/blog/starter-guide-1-configure-your-site/)を参照してください。他のモジュールは[総合案内](/ja/blog/config-reference/)から探せます。

`src/site.config.ts` の最上位で site・theme と同列に指定します。analytics はアクセス解析、aiReadableContent は公開サイト説明で、相互に依存せず、片方のために他方を設定する必要はありません。

<a id="analytics"></a>

## analytics.googleAnalyticsId：GA4 識別子

| パス                        | 型 / 既定値                                               | 状態・役割・制約                                                                                                                                                       | 例                                    |
| --------------------------- | --------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------- |
| analytics                   | { googleAnalyticsId: string } / { googleAnalyticsId: '' } | 設定容器。一部上書き可能で enabled はありません。                                                                                                                      | { googleAnalyticsId: 'G-XXXXXXXXXX' } |
| analytics.googleAnalyticsId | string / ''                                               | 条件付き：有効 ID・本番ビルド・ローカル除外非該当時にロード。空・空白は停止、前後空白は除去。正規表現 ^G-[A-Z0-9]+$ で大文字必須、不正値はコンポーネント解析でエラー。 | 'G-XXXXXXXXXX'                        |

GA4 ウェブデータストリームの Measurement ID です。数値プロパティ ID、GTM コンテナ、旧 UA ID、API キーではありません。例は形式だけなので実 ID に変えます。固定文字数や通信による有効性検証はなく、正規表現通過は受信成功を意味しません。

```ts
analytics: {
  googleAnalyticsId: 'G-XXXXXXXXXX',
},
```

停止する場合の統合例です。

```ts
analytics: { googleAnalyticsId: '' },
```

既存 defineThemeConfig({...}) に統合し、analytics を重複させません。1 ID を共通枠組みの全言語ページで使い、言語・ページ別 ID 項目はありません。

### ロードする条件

| 環境・URL                                  | 現在の動作                                                                     |
| ------------------------------------------ | ------------------------------------------------------------------------------ |
| npm run dev                                | ローダーなし。ただし先に値を解析するため不正形式が無視される保証はありません。 |
| 本番・空 ID                                | ローダーなし。                                                                 |
| 本番・localhost と .localhost サブドメイン | 早期終了し、統計キューも Google 要求も初期化しません。                         |
| 本番・127. 始まり、0.0.0.0、::1、[::1]     | 同様に除外し、比較前に小文字化します。                                         |
| 本番・LAN IP、遠隔プレビュー               | プレビューだからという理由では除外せず、ID があればロードを試みます。          |
| 本番・正式ドメイン・正形式 ID              | gtag キューを1回初期化し、Google クライアントを非同期追加します。              |

js 初期化と config コマンドを実行します。page_view の追加手動送信や検索・音楽などの独自イベントはありません。同じローダーの重複には印がありますが、他のツールで追加した統計は識別しないため、手動 script・GTM との重複を確認してください。

既存 window.dataLayer・window.gtag は保持します。同意管理、同意の自動設定、プロキシ送信、ドメイン除外一覧、独自イベント設定はありません。PUBLIC_GA_* による自動上書きもなく、必要なら自分の site.config で明示処理します。任意の変数名を足しても読みません。

旧独自 adapter の ANALYTICS 分岐不足は未設定として扱う互換処理で、推奨の別パスではありません。指定先は analytics.googleAnalyticsId のみです。

<a id="supplement"></a>

## aiReadableContent：全体の公開補足

任意の MachineReadableSupplement オブジェクトで、テーマ既定は未設定です。省略しても機械可読ファイルは生成し、追加説明だけがありません。{} もエクスポート停止にはなりません。

| 完全パス                        | 型 / 既定値                                             | 状態・役割・制約                                                                                                 | 例                                                            |
| ------------------------------- | ------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------- |
| aiReadableContent.notes         | 任意 string / 未指定、出力は空                          | 条件付き：公開テキストへの Markdown 補足。空・空白は非表示。本文の置換や特定 AI への私的指示ではありません。     | '本站内容是个人学习笔记，可能持续修订。'                      |
| aiReadableContent.links         | 任意 { label: string; href: string }[] / 未指定、空一覧 | 条件付き：公開リンク。配列全置換、[] で消去。公開の件数制限はなく、対象内容は取得しません。                      | [{ label: '项目主页', href: 'https://example.com/project/' }] |
| aiReadableContent.links[].label | 必須 string / なし                                      | trim 後非空。生成時に改行を空白へ、逆斜線・角括弧をエスケープ。対象からタイトルを自動取得しません。              | '项目主页'                                                    |
| aiReadableContent.links[].href  | 必須 string / なし                                      | 非空、公開ルート URL 基準で解決し HTTP(S) のみ、認証情報不可。不正値はエラーですが存在・アクセスは検証しません。 | 'https://example.com/project/'                                |

notes・links に汎用文字数設定はありません。誤った型、空白ラベル、非ウェブ方式、認証情報付きリンクはビルドを妨げます。補足のコマンド実行やモデルによる説明生成はしません。

### Markdown と相対リンクの扱い

notes は Markdown 文面・書式・コード例を維持します。解析したリンク・画像・参照定義の宛先を絶対 URL 化し、HTTP(S)・認証情報なしを検証します。コード例のリンクは変換しません。任意 HTML の完全検証器やページ撮影サービスではありません。

基準は**Astro base を含む公開ルート URL**で、記事 URL や言語ディレクトリではありません。https://example.com/project/ の例です。

| href または Markdown 宛先       | 解決結果                             |
| ------------------------------- | ------------------------------------ |
| zh/blog/                        | https://example.com/project/zh/blog/ |
| /zh/blog/                       | https://example.com/zh/blog/         |
| https://docs.example.com/guide/ | その外部 URL を維持。                |

先頭 / はドメインルートから計算し、/project/ を自動保持しません。音楽などの BASE_URL 追加とは別規則です。mailto:・tel:・file:・javascript: は不可です。本文の連絡リンクに独自出力規則があっても、この補足が同じ方式を認める意味ではありません。

### 全体の例

```ts
aiReadableContent: {
  notes: '本站内容是个人学习笔记，可能持续修订。详情见[文章列表](zh/blog/)。',
  links: [
    { label: '项目主页', href: 'https://example.com/project/' },
  ],
},
```

<a id="locale-supplement"></a>

## 言語ごとの上書き

完全接頭辞は `i18n.locales.<语言>.aiReadableContent`、任意 MachineReadableSupplement、既定未設定です。役割は全体と同じで、未指定は項目ごとに全体値を継承します。

| 相対項目      | 型 / 既定値                                                | 役割と制約                                                           | 例                   |
| ------------- | ---------------------------------------------------------- | -------------------------------------------------------------------- | -------------------- |
| notes         | 任意 string / 全体 notes を継承                            | 言語別補足。''・空白は明示消去し、他言語へ補完しません。             | '中文内容持续更新。' |
| links         | 任意 { label: string; href: string }[] / 全体 links を継承 | 全配列を置換、[] で消去し、全体へ追加マージしません。                | []                   |
| links[].label | 必須 string / なし                                         | 独自項目では必須、全体と同じ検証・エスケープ。                       | '中文文章'           |
| links[].href  | 必須 string / なし                                         | 独自項目では必須、基準は公開ルートで言語ディレクトリではありません。 | 'zh/blog/'           |

簡体中国語の説明だけを変え、追加リンクを消す例です。

```ts
i18n: {
  locales: {
    zh: {
      aiReadableContent: {
        notes: '中文内容持续更新。',
        links: [],
      },
    },
  },
},
```

notes だけなら links は全体を継承し、{} は両方を継承します。undefined は無視し消去にはなりません。meta.fallback には従わず、英語などからコピーしません。[言語リファレンス](/ja/blog/config-languages/#fallback)を参照してください。

ルート llms.txt は常に全体補足を使い、言語別は言語索引・全文・記事 Markdown に使います。全言語で消去しても不正な全体補足を回避できず、ルートが処理します。

<a id="outputs"></a>

## 補足が入る公開出力

公開ルートからの相対パスで、サブパスなら接頭辞を加えます。実際に出力内容のある言語だけ索引と全文を作り、補足を設定しても記事は生まれません。

| 出力                        | 位置と内容                                                                                       |
| --------------------------- | ------------------------------------------------------------------------------------------------ |
| llms.txt                    | 全体 notes は言語一覧の前、links は追加リンク欄。記事がなくても全体補足を含められます。          |
| `<语言>/llms.txt`           | 言語上書きの説明・リンクを使い、Articles / Fragments / About 別に実在公開文書へリンク。          |
| `<语言>/llms-full.txt`      | 言語の全文集合。説明・リンクは各文書の前。                                                       |
| 記事 index.md など          | 元本文の後に区切り、サイト補足ラベル、有効説明を追加し、記事作者本文に混ぜません。               |
| `<语言>/about/index.md`     | 公開紹介・連絡先と到達可能な AI 静的テキスト。末尾へ同規則で補足し、ツール設定全体は出しません。 |
| `<语言>/fragments/index.md` | 全ページを統合し安定 ID リンクを維持。末尾へ補足し、ページ別の重複全文は作りません。             |

個別パスは出力 HTML に従い、index.html は index.md です。独自 Astro 出力では異なるため、手動で生成パスを作って上書きしないでください。Markdown・言語索引への発見リンクも追加します。

対象はマークされた公開インデックス可能・同一オリジン canonical の記事、About、Fragments です。通常ホーム・一覧・Decoder フォーム・コメント iframe は記事として出しません。ビルド内容からリンク・コード・表などを変換し、未描画の任意設定は公開しません。About の AI ダイアログも公開静的文なので公開資料として記入してください。

search: false は Pagefind だけで、この出力は除外しません。notes/links の消去も本文を止めません。aiReadableContent.enabled、記事除外、AI アドレス、モデル引数、API key はありません。公開資料の提供で、モデルの取得・引用・順位向上は保証しません。

自身の過去マニフェスト外の同名ファイルは保護して競合エラーにします。public・出力先へ同パスの llms.txt・Markdown を手置きしないでください。元設定を修正して再ビルドし、出力全体を配備します。ビルド成功だけでオンライン更新やモデルの読取を意味しません。

<a id="boundaries"></a>

## 関連設定と現在の範囲

- 公開 URL は site.url、環境変数、Astro base に影響されます。ルート索引の見出し・説明はサイト文脈を使います。[配備ガイド](/ja/blog/starter-guide-deployment/)を参照し、補足内の URL だけを変えて canonical が変わると期待しないでください。
- 言語スイッチは標準ページに影響しますがホストの旧ファイルを自動削除しません。補足は訳文を作りません。[言語リファレンス](/ja/blog/config-languages/#ai-context)を参照してください。
- GA4 は解析ロードだけで、検索・RSS・機械可読出力は制御しません。静的補足にも固有ボタン・翻訳文面・解析スイッチはありません。
- GA4 ID と補足全項目には使用箇所があり、追加の廃止項目は不要です。旧 adapter の分岐不足は無効として互換処理するだけで有効化方法ではありません。

変更後は再ビルド・再配備します。解析はブラウザー遮断・ネットワーク・解析側設定にも影響され、ローカルのテキスト生成確認で本番解析の確認を置き換えられません。[総合案内](/ja/blog/config-reference/)で他項目を調べられます。
