Чтобы сначала заменить представление, прочитайте [настройку страниц](/ru/blog/starter-guide-3-comments-about-and-theme-toggles/). Установка/файл — в [первом руководстве](/ru/blog/starter-guide-1-configure-your-site/), остальные модули — в [общем справочнике](/ru/blog/config-reference/).

About не читает текст Markdown-статьи. Контент — `i18n.locales.<locale>.about` в `src/site.config.ts`, заголовки страницы/разделов — `messages.about` того же языка. Ниже стандарты пакета, не личное представление demo.

<a id="page-enabled"></a>

## theme.enableAboutPage: переключатель страницы

- **Тип / стандарт:** boolean / true.
- **Состояние и действие:** действует. Создаёт `/<locale>/about/` включённых языков; отключение убирает стандартную страницу и её цели общей навигации/Contact.
- **Ограничения:** не скрывает один абзац и не удаляет конфигурацию. Прямой заход не перенаправляется автоматически на главную. Нужна новая сборка/размещение; отключение не гарантирует удаления старого размещения/открытых данных.
- **Пример:** `theme: { enableAboutPage: false }`.

<a id="about-content"></a>

## Контент и инструменты About

Префикс всех таблиц — **`i18n.locales.<locale>.about.`**, например `i18n.locales.zh.about.sections.who`. Типы до слияния, все поля можно опустить с дополнением через откат и стандарты. Текущие zh/en используют общие английские заполнители, поэтому у них один столбец стандарта. Другие языки могут иметь самостоятельный перевод; не выводите его из этих английских значений.

Общей проверки длины/URL строк нет. Используйте подходящие короткие тексты, настоящие адреса/ссылки. Массивы string[] заменяются целиком. Пустота не универсальное отключение, правила в строках. Пример — значение в нужной вложенности.

### Эффекты

| Поле                       | Тип      | Стандарт zh / en                                                  | Состояние, действие и ограничения                                                                                  | Пример                         |
| -------------------------- | -------- | ----------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ | ------------------------------ |
| `effects.backgroundLines`  | string[] | effects.backgroundLines в [стандартных массивах](#array-defaults) | Стандартный About сейчас не показывает; только fallback без интерактивного terminal session, не переключатель фона | `["~ $ hello","ready"]`        |
| `effects.scrollToasts.p30` | string   | `"context parsed"`                                                | Условно: прокрутка 30%, пустота возвращает context parsed                                                          | `"Вы дочитали до этого места"` |
| `effects.scrollToasts.p60` | string   | `"inference stable"`                                              | Условно: прокрутка 60%, пустота возвращает inference stable                                                        | `"Продолжить знакомство"`      |
| `effects.scrollToasts.p90` | string   | `"output finalized"`                                              | Условно: прокрутка 90%, пустота возвращает output finalized                                                        | `"Спасибо за чтение"`          |

Основной текст выводится обычным текстом, не Markdown/HTML. Стили сохраняют переводы строк. **Жирный**, синтаксис ссылок или HTML внутри строки не создают rich text. Очистка текста не удаляет заголовок/оглавление. Порядок и якоря who/what/ethos/now/contact фиксированы.

Для `scriptsPath` рекомендуется короткий абсолютный виртуальный путь от /, например /home/me/notes, без переносов, NUL и конфликтов файлов. Терминал нормализует ., .. и повторные слеши. Более 1024 символов или недопустимые управляющие символы могут сломать инициализацию виртуальной FS. Это не shell и не чтение произвольных каталогов сервера. Файлы — статьи языка и `about.md`, создаваемые темой. All Scripts не список выполняемых пользовательских скриптов.

DL Data — анимация прогресса, не загрузка. model/latency AI-панели тоже статические, не реальное состояние модели. Замените настоящими личными сведениями или явно обозначьте демонстрацию.

Три текста статистики Help вставляются скриптом в HTML панели. Рекомендуются доверенные короткие обычные тексты, без внешнего ввода в конфиг. Пустота возвращает английский, не очищает. Рендер текста About/строк AI другой: не считайте весь конфиг поддерживающим HTML.

Подсказки прокрутки считаются по всему документу и после начала прокрутки срабатывают максимум раз на порог за инициализацию. Это не число прочитанных слов/AI-прогресс. Публичных порогов/длительности нет, пустая строка не выключает.

### Стандарты трёх массивов

Полные реальные zh/en-массивы, порядок/пустые строки значимы; замена массива заменяет все элементы.

**sections.ethos**

```json
[
  "Prioritize clarity before complexity.",
  "Favor maintainable systems over one-off solutions.",
  "Ship in small iterations and learn from feedback.",
  "Communicate directly and document decisions."
]
```

**modals.ai.lines**

```json
[
  "~ $ ai --status --verbose",
  "",
  "model: anglefeint-core",
  "mode: reasoning + builder",
  "context window: 128k",
  "tools: codex / cursor / claude-code",
  "latency: 120-220ms",
  "safety: guardrails enabled",
  "",
  ">> system online",
  ">> ready for execution"
]
```

**effects.backgroundLines**

```json
[
```

## Пример для объединения

Добавьте в существующий `defineThemeConfig({...})` `src/site.config.ts`, сохранив import/export и личные настройки без второго theme/i18n.

```ts
theme: { enableAboutPage: true },
i18n: {
  locales: {
    ru: {
      about: {
        metaLine: '$ profile ready',
        sections: {
          who: 'Я фронтенд-разработчик.',
          what: 'Создаю личный блог и инструменты с открытым кодом.',
          ethos: ['Сначала ясность.', 'Небольшие регулярные обновления.'],
          now: 'Сейчас изучаю Astro.',
          contactLead: 'Буду рад общению.',
          signature: 'Сохраняйте любопытство.',
        },
        contact: {
          email: 'hello@example.com',
          githubUrl: 'https://github.com/yourname',
          githubLabel: 'GitHub',
        },
        scriptsPath: '/home/me/notes',
        modals: {
          allScripts: { title: 'Список статей' },
          ai: { lines: ['~ $ tools --list', 'Astro / TypeScript'] },
        },
      },
      messages: {
        about: { title: 'Обо мне', description: 'Мой опыт, работа и интересы.' },
      },
    },
  },
},
```

Конфигурация рекурсивно объединяется по цепи от низкого к высокому приоритету, текущий перекрывает резервный, базовый About дополняет. Массивы целиком, undefined игнорируется. Один zh не меняет все языки. Включение/цепь — в [языковом руководстве](/ru/blog/starter-guide-languages/).

## Связанные настройки и отсутствующие возможности

- **Навигация/оглавление:** `i18n.locales.<locale>.messages.nav.about` — общий вход и повторное открытие окна, string, настоящие стандарты китайский «关于» / английский «About», пример «Обо мне». `messages.blog.toc` — название/доступность оглавления About, string, китайский «文章目录» / английский «On this page», пример «На этой странице», также статьи: [тексты статьи](/ru/blog/config-article/#article-messages).
- **Полный декодер:** `theme.enableDecoderPage` boolean true, `theme: { enableDecoderPage: false }` убирает отдельный Decoder и переход из окна, не встроенный About-декодер. Внутри используются `messages.decoder`/`messages.decoderPage` из [Decoder](/ru/blog/config-decoder/), не пять старых decryptor-полей выше.
- **Терминал:** `messages.terminal` — общие интерактивные тексты, не `about.effects.backgroundLines`. Это ограниченная виртуальная веб-FS, конфиг не разрешает программы компьютера. 16 полей/маркеры/неиспользуемое — в [терминале](/ru/blog/config-terminal/).
- **Окна/анимация:** нет публичных размеров About, начального закрытия, fade-in текста, скрытия инструментов, порядка оглавления, имени Oracle или его выключения. Состояние — runtime/локальное хранилище. Без JavaScript текст читается, инструменты не гарантируются. Текст виден сразу без IntersectionObserver. Reduced Motion обрабатывается runtime, не новый переключатель статьи.
- **Контакты:** contact About независим от `social.links`; социальный подвал не меняет контактный абзац.

Пять старых decryptor-полей принимаются типом, но не потребляются. `backgroundLines` только fallback, `modalOutput` начальный заполнитель, состояния отмечены. Не настраивайте ими текущие инструменты и не меняйте реализацию ради старых фраз.
