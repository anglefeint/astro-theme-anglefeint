**Примечание о версии:** Реакция на изменение уменьшения движения и согласованные ключи автора/изображения доступны с 0.36.1; в 0.36.0 этих исправлений нет.

[Назад к общему справочнику](/ru/blog/config-reference/). Сначала различайте файл: глобальные функции/тексты — `src/site.config.ts`, заголовок, даты, изображения и статистика статьи — frontmatter Markdown/MDX. Не меняйте их местами.

Описан стандартный маршрут пакета. Он создаёт страницы включённых языков, оглавление, статистику, переводы и до трёх других статей по реальному контенту. Прямой пользовательский вызов BlogPost должен сам передать атрибуты: всё поведение маршрута автоматически не появляется.

## 1. Глобальные переключатели

<a id="feature-switches"></a>

Поля theme в site.config, все `boolean` со стандартом `true`. Примеры объединяются с theme по необходимости, это не предложение выключить всё.

| Полный путь                    | Действие и условия                                              | Ограничения и пример                                                                                                            |
| ------------------------------ | --------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| `theme.toc.enabled`            | Оглавление из Markdown h2/h3 компилятора, скрыто без заголовков | toc true/false статьи приоритетнее; компоненты/сырой HTML не собираются; `toc: { enabled: false }`                              |
| `theme.math.enabled`           | Математика Markdown/MDX, CSS только при маркерах формул         | Глобально, индивидуального math нет; ошибка формулы ломает компиляцию, отключение меняет парсинг; `math: { enabled: false }`    |
| `theme.effects.enableRedQueen` | Боковой монитор Red Queen                                       | false не выключает сеть фона, Canvas обложки и всю AI-атмосферу; `effects: { enableRedQueen: false }`                           |
| `theme.search.enabled`         | Вход/индекс; [поиск](/ru/blog/config-search/#enabled)           | search false статьи исключает, true не обходит глобальный false; `search: { enabled: false }`                                   |
| `theme.tags.enabled`           | Ссылки статьи и страницы тегов                                  | false не удаляет tags; `tags: { enabled: false }`, [списки](/ru/blog/config-blog-list/#tags-enabled)                            |
| `theme.socialImage.enabled`    | Автопревью 1200×630 без явного ogImage                          | false сохраняет ручной ogImage, откатывает к обложке/стандарту, не скрывает обложку страницы; `socialImage: { enabled: false }` |

Все условны по контенту, области и приоритетам. Например, только стандартное оглавление:

```ts
theme: { toc: { enabled: false } },
```

h3 вкладываются в h2, отдельные h3 тоже входят. h4 и глубже нет. Текст появляется сразу, оглавление не обязательный этап ожидания.

## 3. Поля статьи: не в site.config

<a id="frontmatter"></a>

Все 22 поля frontmatter, не новые site.config-поля. Типы начинаются с ввода автора: даты становятся Date, локальные картинки — метаданными.

### Контент и метаданные

| Поле          | Тип и стандартное поведение                                    | Действие, ограничения и пример                                                          |
| ------------- | -------------------------------------------------------------- | --------------------------------------------------------------------------------------- |
| `title`       | Обязательная string без стандарта                              | Заголовок/метаданные, не название сайта; `title: '我的笔记'`                            |
| `description` | Обязательная string без стандарта                              | Метаописание и context при отсутствии; не весь текст; `description: '一次调试的记录。'` |
| `pubDate`     | Обязательная разбираемая дата                                  | Публикация/порядок/метаданные, показ UTC; будущее не скрывает; `pubDate: '2026-11-13'`  |
| `updatedDate` | Необязательная дата, отсутствует                               | Дата обновления/приоритет sitemap, не порядок; `updatedDate: '2026-11-14'`              |
| `author`      | Необязательная string, отсутствие/пробелы — автор сайта        | Страницу автора не создаёт; `author: '另一位作者'`                                      |
| `subtitle`    | Необязательная string, отсутствует                             | Подзаголовок без дубля совпадающего context; `subtitle: '从现象到定位'`                 |
| `context`     | Необязательная string, иначе description                       | Под заголовком, '' скрывает без очистки метаописания; `context: '解决一个具体问题。'`   |
| `tags`        | Необязательный string[], иначе без тегов                       | Ссылки зависят от глобального; `tags: ['astro', '笔记']`                                |
| `heroImage`   | Необязательный локальный путь, иначе без обложки               | Не удалённый/public URL по тем же правилам; `heroImage: ./cover.jpg` с готовым файлом   |
| `ogImage`     | Необязательный локальный/public/HTTPS, иначе приоритеты превью | Не меняет обложку текста; `ogImage: /images/share.png` с файлом                         |
| `toc`         | Необязательный boolean, глобальное наследование                | true обходит глобальный false, но без заголовков скрыто; `toc: false`                   |
| `search`      | Необязательный boolean, true                                   | false исключает только внутренний поиск, не статьи/RSS/sitemap/AI; `search: false`      |

Начните с обязательного и дополните:

```yaml
---
title: '我的笔记'
description: '一次调试的记录。'
pubDate: '2026-11-13'
subtitle: '从现象到定位'
context: '解决一个具体问题。'
tags: ['astro', '笔记']
toc: true
search: true
---
```

Нет draft, расписания, comments, Red Queen или math одной статьи. Неготовое держите вне каталога контента, неизвестное поле не контроль приватности.

<a id="output-fields"></a>

### Статистика OUTPUT и статусы

| Поле         | Тип и стандартное поведение                                                 | Действие, ограничения и пример                                              |
| ------------ | --------------------------------------------------------------------------- | --------------------------------------------------------------------------- |
| `wordCount`  | Необязательное неотрицательное целое, иначе подсчёт исходного текста        | Независимое число, не меняет tokenCount; `wordCount: 800`                   |
| `tokenCount` | Необязательное неотрицательное целое, иначе round(max(自动字词数, 1) × 1.3) | Оценка, не токенизатор/расход; `tokenCount: 1040`                           |
| `aiModel`    | Необязательная string, иначе без ярлыка                                     | Статус заголовка/OUTPUT, без проверки модели; `aiModel: '作者填写的模型名'` |
| `aiMode`     | Необязательная string, иначе без ярлыка                                     | Только режим, не выполнение; `aiMode: 'notes'`                              |
| `aiState`    | Необязательная string, иначе без ярлыка                                     | Только текст, не здоровье сервиса; `aiState: 'edited'`                      |

Автоподсчёт убирает часть Markdown/кода/ссылок; CJK, кана и корейский посимвольно, остальное преимущественно по пробелам. Формулы/MDX могут влиять. wordCount не пересчитывает tokenCount. От 1000 формат одной десятичной k без изменения исходного значения.

```yaml
wordCount: 800
tokenCount: 1040
aiModel: '作者填写的模型名'
aiMode: 'notes'
aiState: 'edited'
```

<a id="legacy-frontmatter"></a>

### Совместимые и сейчас неиспользуемые поля

| Поле             | Тип и стандарт                                    | Состояние, ограничения и пример                                                                                                           |
| ---------------- | ------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| `readMinutes`    | Необязательное положительное целое, отсутствует   | Совместимость, время чтения не показывается; `readMinutes: 3` не возвращает                                                               |
| `aiLatencyMs`    | Необязательное неотрицательное целое, отсутствует | Совместимость, задержка не показывается; `aiLatencyMs: 150` не измерение                                                                  |
| `aiConfidence`   | Необязательный number 0–1, отсутствует            | Совместимость, уверенность не показывается; `aiConfidence: 0.9` не оценка точности                                                        |
| `canonicalTopic` | Необязательная string, отсутствует                | Сейчас не используется; `canonicalTopic: 'astro'` не создаёт тему/canonical                                                               |
| `sourceLinks`    | Необязательный массив адресов, отсутствует        | Только проверка/нормализация HTTP(S), голый домен получает https; `sourceLinks: ['https://example.com/']` не показывает источники/экспорт |

Для читателя укажите Markdown-ссылки в тексте. Принятый старый тип не подтверждает оставшийся UI; ради обновления удалять данные не требуется.

## 4. Тексты интерфейса статьи

<a id="article-messages"></a>

Префикс `i18n.locales.<语言>.messages.blog`. Необязательные string с обычным откатом; ниже настоящие встроенные упрощённый китайский/английский. Пример — член blog, не frontmatter.

Действующие тексты условны при области. Пустота может очистить label, не скрыть функцию; доступные имена не очищайте. Неиспользуемые эффекта не имеют.

| Поле                 | Стандарт упрощённого китайского / английского | Действие и ограничения                                  | Состояние              | Пример члена                      |
| -------------------- | --------------------------------------------- | ------------------------------------------------------- | ---------------------- | --------------------------------- |
| `rqBadge`            | 监视器信号 / monitor feed                     | Значок включённого Red Queen, не настоящий мониторинг   | Условно                | `rqBadge: "监视器信号"`           |
| `rqReplayAria`       | 重放监视器信号 / Replay monitor feed          | Имя повтора, не материал/стратегия                      | Условно                | `rqReplayAria: "重放监视器信号"`  |
| `backToTop`          | 返回顶部 / Back to top                        | Имя наверх, показ по прокрутке                          | Условно                | `backToTop: "返回顶部"`           |
| `toastP10`           | 语境解析 10% / context parsed 10%             | Ранний прогресс чтения, не AI-запрос                    | Условно                | `toastP10: "语境解析 10%"`        |
| `toastP30`           | 语境解析 30% / context parsed 30%             | Чтение, не результат семантического анализа             | Условно                | `toastP30: "语境解析 30%"`        |
| `toastP60`           | 推理稳定 60% / inference stable 60%           | Чтение, не состояние вывода модели                      | Условно                | `toastP60: "推理稳定 60%"`        |

| `systemModelLabel`   | 模型 / model                                  | Метка aiModel, также OUTPUT                             | Условно                | `systemModelLabel: "模型"`        |

| `regenerate`         | 重播扫描 / Replay scan                        | Повтор сканирования, только визуальный                  | Условно                | `regenerate: "重播扫描"`          |
| `relatedAria`        | 相关文章 / Related posts                      | Доступное имя при других статьях                        | Условно                | `relatedAria: "相关文章"`         |
| `related`            | 相关文章 / Related                            | Заголовок, не рекомендации                              | Условно                | `related: "相关文章"`             |

| `comments`           | 评论 / Comments                               | Доступное имя при действительной конфигурации           | Условно                | `comments: "评论"`                |
| `metaReadMinutes`    | 分钟阅读 / min read                           | Не используется, время чтения не возвращает             | Сейчас не используется | `metaReadMinutes: "分钟阅读"`     |
| `latencyLabel`       | 延迟估计 / latency est                        | Не используется, задержку не возвращает                 | Сейчас не используется | `latencyLabel: "延迟估计"`        |

Статусы, обложка и подсказки чтения создают атмосферу, не подтверждают AI online, сеть или точность. regenerate только повторяет визуальный скан, не переписывает статью/запрашивает AI.

Пример OUTPUT и ссылки раздела:

```ts
i18n: {
  locales: {
    zh: {
      messages: {
        blog: {
          responseOutput: '正文',
          statsWords: '字词',
          statsTokens: '估算 tokens',
          copySectionLink: '复制这一节的网址',
          regenerate: '重播扫描效果',
        },
      },
    },
  },
},
```

Возврат ведёт в блог текущего языка независимо от текста. Рекомендации — до трёх последних того же языка без текущей, не AI-сходство. Полей количества/сходства нет, related/relatedAria только тексты/доступность.

<a id="interaction-messages"></a>

### Копирование кода и просмотр изображений

Префикс теперь `i18n.locales.<语言>.messages`. Все необязательные string, условно действуют, не меняют права копирования/источник и не добавляют переключатели.

| Конец пути           | Стандарт упрощённого китайского / английского                       | Действие и ограничения                   | Пример члена                                         |
| -------------------- | ------------------------------------------------------------------- | ---------------------------------------- | ---------------------------------------------------- |
| `codeCopy.copy`      | 复制代码 / Copy code                                                | Текст кнопки, не копируемое              | `codeCopy: { copy: "复制代码" }`                     |
| `codeCopy.copied`    | 已复制 / Copied                                                     | Успех кода/ссылки раздела                | `codeCopy: { copied: "已复制" }`                     |
| `codeCopy.failed`    | 复制失败，请手动选择代码。 / Copy failed. Select the code manually. | Ошибка кода/ссылки, не разрешения буфера | `codeCopy: { failed: "复制失败，请手动选择代码。" }` |
| `imagePreview.open`  | 查看大图 / View image                                               | Доступное имя входа/окна                 | `imagePreview: { open: "查看大图" }`                 |
| `imagePreview.close` | 关闭图片预览 / Close image preview                                  | Имя закрытия, не источник                | `imagePreview: { close: "关闭图片预览" }`            |

```ts
i18n: {
  locales: {
    zh: {
      messages: {
        codeCopy: { copy: '复制内容', copied: '复制好了', failed: '无法复制，请手动选择。' },
        imagePreview: { open: '放大这张图片', close: '收起图片' },
      },
    },
  },
},
```

Ссылки разделов только у h2/h3 текста с id, успех/ошибка общие codeCopy.copied/failed. Копирование/просмотр требуют JavaScript. Просмотр обычных изображений исключает обложки и вложенные в ссылки/кнопки; использует выбранный источник без нового HD-оригинала. site.config enabled у них нет.

## 5. Границы конфигурации и проверка

Страница статьи реагирует на изменение системной настройки уменьшения движения без перезагрузки. При включении обложка и фоновая сеть становятся статичными, Red Queen останавливается и скрывается; при выключении эффекты возвращаются с прежними задержками запуска. Прогресс чтения не сбрасывается, копирование кода, ссылки разделов и просмотр изображений не привязываются заново. Новый переключатель site.config не добавляется.

Текст/панель появляются сразу и неподвижны; сеть фона, световая полоса и обложка независимы. Нет публичных глобального переключателя AI-темы, длительности входа, дыхания панели, количества рекомендаций, imagePreview enabled или codeCopy enabled. Произвольный ключ не работает.

locale, articleSlug, headings, filePath, related, localeHrefs и seoLocaleHrefs — атрибуты BlogPost, не site.config/frontmatter. Стандартный маршрут предоставляет данные, обычной статье заполнять их не нужно.

В dev проверьте контент с/без заголовков и обложки, самостоятельно копирование/разделы/изображения. Поиск — в собранном preview. Перед публикацией остановите dev, выполните npm run doctor и npm run preview, не повторяя check/build после успеха. Онлайн обновится после размещения.
