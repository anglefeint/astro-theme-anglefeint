Различайте поиск статей по индексу сборки и прочие входы: последние статьи главной, теги, рекомендации и RSS не подчиняются одному переключателю поиска. Стандарты ниже из пакета, не переопределения demo.

<a id="enabled"></a>

## theme.search.enabled: общий переключатель поиска

- **Тип / стандарт:** boolean / true.
- **Состояние и действие:** действует. Общая шапка показывает вход, участвующие статьи получают индексные маркеры, после сборки создаются статические ресурсы Pagefind.
- **Ограничения:** false отключает стандартный вход и создание индекса этой сборки. search: true отдельной статьи не обходит глобальный false. Отключение не удаляет статьи, не запрещает внешнюю индексацию и не очищает старые файлы индекса хостинга.
- **Пример:** theme: { search: { enabled: false } }.

Это единственное публичное конечное поле theme.search. Адреса сервиса, API key, каталога индекса, сортировки, веса слов или межъязыкового переключателя нет. Используется Pagefind при сборке, отдельный поисковый backend после размещения не нужен.

<a id="article-search"></a>

## search статьи: не поле site.config

| Место                                                      | Тип / стандарт                                                         | Состояние, действие и ограничения                                                                                                                  | Пример        |
| ---------------------------------------------------------- | ---------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- | ------------- |
| frontmatter.search в `src/content/blog/<locale>/statya.md` | boolean, необязателен / schema не задаёт, макет статьи использует true | Условно: при глобальном поиске определяет корневой маркер статьи. false не влияет на списки, рекомендации, RSS, машинный экспорт или публичный URL | search: false |

Для исключения только из внутреннего поиска добавьте в существующий frontmatter:

```yaml
search: false
```

Не записывайте theme.search: false или верхнеуровневый search: false в site.config. frontmatter.search не делает статью приватной. draft/будущая дата не фильтруются; непубличный контент держите вне коллекции. Поля — в [справочнике статьи](/ru/blog/config-article/#frontmatter).

### Что входит в индекс?

Стандартный макет выводит корень data-anglefeint-search при разрешении глобального и индивидуального переключателей. Отмеченная область включает заголовок, видимый подзаголовок и текст. context, совпадающий с subtitle, обрабатывается один раз на месте подзаголовка; отдельного индекса поля для всех context нет.

Навигация, проигрыватель, подвал, комментарии и рекомендации не индексируются как текст статьи. frontmatter.description не является напрямую используемым UI-сниппетом, теги не являются настраиваемым фильтром. Используются метаданные заголовка и сниппет текста Pagefind. Текст только в пикселях изображений, видео или аудио не распознаётся/транскрибируется.

У стандартных About, Fragments, Decoder, главной и списков нет корневого маркера статьи, включение поиска не делает их результатами автоматически. Собственная страница должна соблюдать контракт маркеров сама; произвольного site.config-поля для этого нет.

## messages.search: одиннадцать текстов

Полный префикс — `i18n.locales.<locale>.messages.search.`. Все необязательные string, стандарт — встроенный язык и цепочка отката. Ниже настоящие значения упрощённого китайского/английского и примеры полей. Условно действуют при входе поиска и соответствующем интерфейсе/состоянии.

| Поле          | Стандарт упрощённого китайского / английского                                                                                        | Действие, ограничения и маркеры                                                                        | Пример                                      |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------ | ------------------------------------------- |
| `label`       | 搜索 / Search                                                                                                                        | Доступное имя входа, подсказка и заголовок окна, не поисковая фраза                                    | `"Искать статьи"`                           |
| `close`       | 关闭搜索 / Close search                                                                                                              | Доступное имя/подсказка закрытия; esc и значок фиксированы                                             | `"Закрыть поиск"`                           |
| `placeholder` | 搜索文章… / Search articles…                                                                                                         | Placeholder и доступный label, не готовый запрос                                                       | `"Введите ключевые слова"`                  |
| `hint`        | 搜索当前语言的文章。 / Search articles in the current language.                                                                      | Подсказка production до ввода                                                                          | `"Поиск статей на текущем языке."`          |
| `loading`     | 正在搜索… / Searching…                                                                                                               | Поиск/подготовка поиска, не задержка или стратегия ресурсов                                            | `"Поиск…"`                                  |
| `empty`       | 没有找到匹配的文章。 / No matching articles.                                                                                         | Нет результатов, в том числе возможное отсутствие индекса языка                                        | `"Похожие статьи не найдены."`              |
| `error`       | 搜索加载失败，请重试。 / Search could not load. Please try again.                                                                    | Ошибка манифеста, модуля или деталей; не ошибка генерации сборки                                       | `"Поиск недоступен; попробуйте снова."`     |
| `retry`       | 重试 / Retry                                                                                                                         | Повтор загрузки механизма, не перестройка индекса браузером                                            | `"Перезагрузить"`                           |
| `more`        | 加载更多 / Load more                                                                                                                 | Загрузка оставшихся результатов без изменения размера партии                                           | `"Больше результатов"`                      |
| `results`     | 找到 {count} 篇文章 / {count} articles found                                                                                         | Общее число найденного; сохраните один {count}, заменяется первое вхождение, не число видимых карточек | `"Найдено статей: {count}"`                 |
| `dev`         | 本地完整搜索请先运行 npm run build，再运行 npm run preview。 / To test full search locally, run npm run build, then npm run preview. | Подсказка dev без настоящей индексации; смена текста индекс не создаёт                                 | `"После сборки проверьте поиск в preview."` |

Тексты не выполняют HTML. Пустая строка меняет надпись, не скрывает кнопку и может лишить доступного имени. {count} не добавляется автоматически к вашему предложению: оставьте маркер для числа.

### Пример для объединения

Добавьте в существующий defineThemeConfig({...}) в src/site.config.ts, сохранив import/export и личные настройки без повторных theme/i18n:

```ts
theme: { search: { enabled: true } },
i18n: {
  locales: {
    ru: {
      messages: {
        search: {
          label: 'Искать статьи',
          placeholder: 'Введите ключевые слова',
          results: 'Найдено статей: {count}',
          empty: 'Похожие статьи не найдены.',
        },
      },
    },
  },
},
```

## Язык, загрузка и результаты

- Сборка создаёт pagefind/ с anglefeint.json языков и модулями. Манифест/движок загружаются при открытии поиска, но UI-скрипт — со страницей входа; не весь код ждёт щелчка.
- Пути автоматически включают Astro BASE_URL. Один HTML, пропущенный pagefind/ или переписывание ресурсов в HTML вызывают ошибки. Отдельного пути индекса в site.config нет.
- Клиент сопоставляет html lang документа со списком языков без учёта регистра. Нет индекса текущего языка — пустой результат, не английский поиск. Используется действительный язык страницы, не язык отката UI.
- Поиск примерно через 200 мс после ввода, после завершения китайской IME-композиции; submit запускает сразу. Пустой запрос не ищет. Задержка не конфигурация и не запрос удалённого AI.
- До 8 подробных результатов за партию, далее «ещё»; pageSize нет. Счётчик — общий итог, не партия. Ссылки только того же origin, сниппеты — текст и mark-подсветка, не произвольный HTML статьи.
- Порядок даёт Pagefind без параметров алгоритма рекомендаций/сортировки темы. Откат интерфейса не дополняет результат статьями другого языка.

Метаданные, включение и откаты — в [языках](/ru/blog/config-languages/#meta). Тексты search не создают статьи/индексы других языков.

<a id="preview"></a>

## Почему в dev нет настоящего поиска?

Индекс создаётся после сборки Astro, npm run dev этого не делает. Показывается messages.search.dev, ввод не выполняет настоящий поиск. Это текущее поведение, не потерянная настройка.

После подготовки контента запустите локально:

```bash
npm run build
npm run preview
```

preview использует сборку. После изменения статей, языковых метаданных, search отдельной статьи или пути нужна новая сборка для нового индекса. Размещайте страницы и pagefind вместе. Изменение UI в dev не обновляет онлайн-индекс.

Без индексируемых статей всё равно создаётся распознаваемый пустой список языков для пустых результатов. Ошибка индексации останавливает сборку, не выдаёт ложный успех. Повтор читает существующие ресурсы, не исправляет сборку и не создаёт статьи в браузере посетителя.

## Что управляет другими входами контента?

Ниже существующие поля других модулей; их основное описание не дублируется новой системой поиска.

| Путь или место                                    | Тип / стандарт                                                | Действие, ограничения и пример                                                                                 | Подробности                                                |
| ------------------------------------------------- | ------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------- |
| theme.homeLatestCount                             | number / 3                                                    | Последние статьи главной; theme: { homeLatestCount: 5 }. Не партии поиска и не рекомендации                    | [Главная](/ru/blog/config-home/#latest-count)              |
| theme.blogPageSize                                | number / 10                                                   | Размер Blog List/тегов; theme: { blogPageSize: 8 }. Не результаты поиска                                       | [Пагинация](/ru/blog/config-blog-list/#page-size)          |
| theme.tags.enabled                                | boolean / true                                                | Входы/страницы тегов; theme: { tags: { enabled: false } }. Не удаляет tags и не выключает полнотекстовый поиск | [Теги](/ru/blog/config-blog-list/#tags-enabled)            |
| frontmatter.tags статьи                           | string[], необязателен / отсутствует                          | Архивы/видимые теги; ['Astro', 'эссе']. Не релевантность рекомендаций и не белый список поиска                 | [Поля статьи](/ru/blog/config-article/#frontmatter)        |
| `i18n.locales.<locale>.messages.blog.related`     | string / встроенный текущего языка, китайский/английский ниже | Заголовок рекомендаций, только текст; 'Читать дальше'                                                          | [Тексты статьи](/ru/blog/config-article/#article-messages) |
| `i18n.locales.<locale>.messages.blog.relatedAria` | string / встроенный текущего языка, китайский/английский ниже | Доступное имя области рекомендаций; 'Другие статьи'                                                            | [Тексты статьи](/ru/blog/config-article/#article-messages) |

Фактически рекомендации — три последних статьи текущего языка без текущей, не общие теги, canonicalTopic или сходство контента. Нет relatedCount, отдельного выключателя или ручного списка. Без других статей область скрыта. search: false не исключает рекомендацию.

| Текст                     | Стандарт упрощённого китайского / английского |
| ------------------------- | --------------------------------------------- |
| messages.blog.related     | 相关文章 / Related                            |
| messages.blog.relatedAria | 相关文章 / Related posts                      |

## RSS, SEO и машинный экспорт — не внутренний поиск

| Вход                            | Текущее поведение и связь                                                                                                                                                                                                                                                              |
| ------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `/<locale>/rss.xml`             | Подписка на описания статей каждого включённого языка. Заголовок — название сайта, описание — messages.blog.archiveDescription языка. Элементы из title/description/pubDate/публичного пути языка. search: false не исключает; это не полный RSS, переключателя RSS в theme.search нет |
| Метаданные и внешние поисковики | Независимая выдача; search: false не ставит noindex и не выключает sitemap, не управляет внешним обходом                                                                                                                                                                               |
| Публичный машинный текст        | Статьи/About/Fragments имеют собственный экспорт, не зависящий от Pagefind. Дополнение языка — в [языках](/ru/blog/config-languages/#ai-context). search: false не фильтр приватности этих файлов                                                                                      |

Заполните реальные название, домен и описание подписки. Адреса/размещение — в [публикации](/ru/blog/starter-guide-deployment/), archiveDescription RSS — в [текстах списка](/ru/blog/config-blog-list/#archive-messages). Отсутствие внутреннего результата не означает непубличность контента.

Общий переключатель, search статьи и одиннадцать текстов потребляются; старых обязательных совместимых полей поиска нет. Непотребляемый canonicalTopic не становится классификатором индекса из-за соседства с поиском; см. [состояние полей статьи](/ru/blog/config-article/#legacy-frontmatter). Нет публичных настроек общего межъязыкового поиска, OCR, аналитики запросов, весов или новых типов индекса.
