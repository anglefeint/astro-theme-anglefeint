Где находится конфигурация — в [установке и данных сайта](/ru/blog/starter-guide-1-configure-your-site/), контент/инструменты — в [About](/ru/blog/config-about/), остальные модули — в [общем справочнике](/ru/blog/config-reference/).

В стандартном сайте интерактивный виртуальный терминал находится в About. Здесь меняются подсказки команд, ошибки и доступные имена просмотрщика, не выполняются shell-команды компьютера или сервера. Авторский текст терминала главной использует messages.home.transmission из [справочника главной](/ru/blog/config-home/#home-transmission), не эти сообщения.

<a id="messages"></a>

## Шестнадцать полей messages.terminal

Полный префикс — `i18n.locales.<locale>.messages.terminal`. Все поля — необязательные string-переопределения со встроенными текстами текущего языка и обычной цепочкой отката. В таблице только настоящие стандарты упрощённого китайского/английского, примеры — значения полей. Нужны включённый About, успешная инициализация терминала и соответствующий результат команды/режим чтения.

| Поле            | Стандарт упрощённого китайского / английского                                                                                       | Состояние, действие и ограничения                                                                                                | Пример                                                                 |
| --------------- | ----------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------- |
| `commandInput`  | 终端命令 / Terminal command                                                                                                         | Условно: доступное имя ввода; не путь prompt и не видимый заголовок панели                                                       | `"Ввод терминала"`                                                     |
| `hint`          | 输入 help 开始探索。Tab 补全唯一路径，↑/↓ 查看历史命令。 / Type help to explore. Tab completes a unique path; ↑/↓ recalls commands. | Условно: строка инициализации About; при запуске также выполняется виртуальный pwd. Пустая строка убирает подсказку, не терминал | `"Введите help для списка команд."`                                    |
| `help`          | 只读虚拟文件，不会在服务器执行命令。 / Read-only virtual files. No commands run on a server.                                        | Условно: пояснение help; фиксированная справка команд остаётся, пустая строка не скрывает весь список                            | `"Просмотр публичных статей только для чтения, без системных команд."` |
| `syntax`        | 引号或转义未结束。 / Unclosed quote or escape.                                                                                      | Условно: незакрытая кавычка/экранирование; пустое возвращает имя syntax                                                          | `"Незакрытая кавычка или escape-последовательность."`                  |
| `usage`         | 用法：{value} / Usage: {value}                                                                                                      | Условно: неверное число аргументов; {value} — синтаксис команды; пустое возвращает usage                                         | `"Использование: {value}"`                                             |
| `unknown`       | 不支持此命令：{value} / Command not supported: {value}                                                                              | Условно: неподдерживаемая команда; {value} — имя; текст не добавляет команды                                                     | `"Неподдерживаемая команда: {value}"`                                  |
| `notFound`      | 文件或目录不存在：{value} / No such file or directory: {value}                                                                      | Условно: отсутствующий виртуальный файл/каталог; {value} — путь, не удалённый HTTP-статус                                        | `"Не найдено: {value}"`                                                |
| `notDirectory`  | 不是目录：{value} / Not a directory: {value}                                                                                        | Условно: цель cd не каталог; {value} — целевой путь                                                                              | `"Не каталог: {value}"`                                                |
| `isDirectory`   | 这是目录：{value} / Is a directory: {value}                                                                                         | Условно: цель cat/vi/vim/view не файл; {value} — путь                                                                            | `"Цель не является файлом: {value}"`                                   |
| `failed`        | 无法读取：{value} / Unable to read: {value}                                                                                         | Условно: общая ошибка чтения; {value} — путь, исходные подробности ошибки не дописываются                                        | `"Не удалось прочитать: {value}"`                                      |
| `tooLarge`      | 文件超过阅读大小限制：{value} / File exceeds the reading limit: {value}                                                             | Условно: превышен предел чтения; {value} — путь. Меняет текст, не реальный лимит                                                 | `"Слишком большой файл: {value}"`                                      |
| `empty`         | （空目录） / (empty directory)                                                                                                      | Условно: пустой ls, не текст пустого файла                                                                                       | `"Каталог пуст."`                                                      |
| `loading`       | 正在读取… / Loading…                                                                                                                | Условно: ожидание команды в позиции Canvas-ввода; пустое даёт ..., стратегию сети не меняет                                      | `"Чтение…"`                                                            |
| `readerTitle`   | 文章阅读器 / Article reader                                                                                                         | Сейчас не используется: тип и текст сохранены, но заголовок берётся из title/path файла; переопределение его не меняет           | `"Читалка статей"`                                                     |
| `readerHint`    | 只读 · 输入 :q 并回车退出 · Esc 关闭 / Read only · :q + Enter to exit · Esc to close                                                | Условно: подсказка чтения; пустое даёт :q. Не меняет команды/клавиши выхода                                                      | `"Только чтение · :q и Enter для выхода · Esc для закрытия"`           |
| `readerCommand` | 阅读器命令 / Reader command                                                                                                         | Условно: доступное имя ввода режима чтения; пустое возвращает имя исходного ввода терминала                                      | `"Ввод команд читалки"`                                                |

<a id="placeholders"></a>

## Маркер {value} и пустые строки

usage, unknown, notFound, notDirectory, isDirectory, failed и tooLarge используют буквальный {value}. Скрипт заменяет только первое вхождение: оставьте одно для команды/пути. {path}, {command} и другие имена не поддерживаются. Подстановка выводится текстом, не выполняется.

Общего правила «пустая строка отключает функцию» нет. Ошибки команд выше и syntax возвращают имя ключа, loading — ..., readerHint — :q, readerCommand — исходный label. hint/help/empty могут очищать текст, не удаляя терминал, фиксированную справку или каталог.

readerTitle сейчас не потребляется и не управляет заголовком читательского интерфейса; наличие стандартной строки в языковом пакете не означает эффект.

<a id="example"></a>

## Пример на русском для объединения

Добавьте в существующий defineThemeConfig({...}) в src/site.config.ts, сохранив остальное без второго i18n. Переопределение русского не меняет остальные языки автоматически; см. [откат языков](/ru/blog/config-languages/#fallback).

```ts
i18n: {
  locales: {
    ru: {
      messages: {
        terminal: {
          commandInput: 'Ввод терминала',
          hint: 'Введите help для списка команд.',
          help: 'Просмотр публичных статей только для чтения, без системных команд.',
          usage: 'Использование: {value}',
          notFound: 'Не найдено: {value}',
          failed: 'Не удалось прочитать: {value}',
          tooLarge: 'Слишком большой файл: {value}',
          readerHint: 'Только чтение · :q и Enter для выхода · Esc для закрытия',
          readerCommand: 'Ввод команд читалки',
        },
      },
    },
  },
},
```

## Какие ещё настройки использует терминал?

| Настройка                                 | Действие для терминала                                                                                                          | Основное описание                                                   |
| ----------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------- |
| theme.enableAboutPage                     | boolean, стандарт true; отключение убирает стандартный About и его терминал                                                     | [About](/ru/blog/config-about/#page-enabled)                        |
| `i18n.locales.<locale>.about.scriptsPath` | string, стандарт /root/bash/scripts; префикс виртуальных путей и начальный каталог, не диск сервера                             | [Инструменты About](/ru/blog/config-about/#tool-fields)             |
| `i18n.locales.<locale>.about.sections`    | Публичное представление участвует в виртуальном about.md, не в ошибках терминала                                                | [Текст About](/ru/blog/config-about/#body-fields)                   |
| Статьи текущего языка                     | Автоматически входят в виртуальный каталог, JSON статьи загружается по требованию; регистрировать каждую в site.config не нужно | [Написание статей](/ru/blog/starter-guide-2-languages-and-routing/) |

sidebar.allScripts и modals.allScripts.title About меняют вход инструмента и окно каталога, не имена команд. effects.backgroundLines не заменяет начальную подсказку текущей интерактивной session; состояние деградации — в [эффектах About](/ru/blog/config-about/#effect-fields).

<a id="limits"></a>

## Фиксированные возможности и ограничения, не поля site.config

- Виртуальные команды: help, clear, pwd, ls, cd, cat, vi, vim, view. About также подключает open, close, minimize, maximize, restore для окон. Список задаёт реализация; изменение help/unknown не добавляет системные команды.
- vi/vim/view открывают чтение, не редактор. :q, :q! или q с Enter выходят, Esc тоже закрывает. readerHint меняет подсказку, не действия.
- Стандартный ввод — до 512 кодовых единиц JavaScript UTF-16, история — до 50 команд. Чтение файла — до 262 144 единиц, затем tooLarge. Есть отдельная ограниченная защита сетевого чтения; это не допустимый размер загрузки файла.
- Статьи читаются по требованию из JSON того же origin. Это не загрузчик произвольных URL и не доступ к локальным каталогам. Виртуальные текстовые файлы/каталоги не обязательно вызывают сеть.
- Размер шрифта, цвет, шрифт, лимит ввода/истории/чтения — внутренние параметры компонентов/функций, публичных путей site.config нет. API key не задан, SSH, настоящий shell и удалённый AI не подключаются.

После сохранения перечитайте dev-конфигурацию, для опубликованного сайта пересоберите и разместите. Для проверки вызовите соответствующую команду/чтение, одного статического заголовка недостаточно; особенно readerTitle сейчас не меняет интерфейс.
