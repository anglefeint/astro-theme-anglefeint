Это руководство 5 из 8. [Порядок всех руководств](/ru/blog/starter-guide-1-configure-your-site/#tutorial-order) · [Справочник настроек](/ru/blog/config-reference/).

Когда блог уже работает, начните с того, что хотите изменить. Заполнять все настройки и копировать все примеры не требуется.

Все TypeScript-фрагменты объединяйте с существующим объектом `defineThemeConfig({...})` в `src/site.config.ts`. В объекте должны оставаться единственные `theme`, `i18n` и `social`; изменяйте существующие поля, сохраняя остальные личные настройки. Объекты объединяются со стандартными значениями, массивы заменяются целиком: добавляя ссылки, песни или записи, включайте и те, которые хотите оставить.

Здесь собраны частые задачи, а не все поля. Найдите область страницы, которую хотите изменить, и нужный раздел.

## 1. Настройте подсказки и эффекты главной

Различия названия сайта, большого заголовка и вступления см. в [первом руководстве](/ru/blog/starter-guide-1-configure-your-site/). Здесь настраиваются подсказки и взаимодействие:

```ts
theme: {
  home: {
    showInitialize: true,
    showFollow: true,
    showTrace: true,
  },
  effects: { enableHomePassage: false },
},
```

| Поле                              | По умолчанию | Что меняется                                                                                                                                   |
| --------------------------------- | ------------ | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| `theme.home.showInitialize`       | `true`       | Строка запуска Initialize/done; false скрывает её                                                                                              |
| `theme.home.showFollow`           | `true`       | Блок Wake Up/Follow; false независимо скрывает его                                                                                             |
| `theme.home.showTrace`            | `true`       | Нижний статус PIRATE SIGNAL/TRACE; false скрывает блок                                                                                         |
| `theme.effects.enableHomePassage` | `false`      | Ссылки заголовков статей главной запускают примерно 8-секундный проход Matrix перед переходом; при уменьшении движения переход остаётся прямым |

Эти поля не выключают весь дождь кода и не переключают глобальную палитру. `showTrace` также не управляет широкоформатным терминалом внизу справа.

### Измените текст широкоформатного терминала

Стандартный текст — `Knock, knock.`. Можно настроить английский как общий для языков без собственного переопределения:

```ts
i18n: {
  locales: {
    en: { messages: { home: { transmission: '记录想法，也留下一点线索。' } } },
  },
},
```

Для отдельного языка используйте его `messages.home.transmission`. Приоритет: настройка текущего языка → английская настройка → `Knock, knock.`, без полной стандартной цепочки языкового отката. Терминал появляется в широком макете; отсутствие на телефоне не означает ошибку. Кнопка замочной скважины открывает превью коридора.

Вход Oracle в About использует отдельное превью сцены и не зависит от переключателя прохода ссылок главной. Тексты терминала и нижнего статуса создают атмосферу, а не сообщают настоящие данные компьютера, сети или безопасности.

Полные определения см. в [справочнике главной](/ru/blog/config-home/#startup-switches).

## 2. Замените About своим описанием

Текущее содержимое доступно на `/zh/about/`. Текст и контакты задаются для языка без изменения шаблона страницы:

```ts
i18n: {
  locales: {
    zh: {
      about: {
        metaLine: '$ profile | building and learning',
        sections: {
          who: '我是小林，喜欢开发与写作。',
          what: '这里记录我的项目和学习笔记。',
          ethos: ['保持好奇。', '把想法变成可以使用的东西。'],
          now: '最近在整理个人博客。',
          contactLead: '欢迎联系我。',
          signature: '> 谢谢你来这里。',
        },
        contact: {
          email: 'you@example.com',
          githubUrl: 'https://github.com/yourname',
          githubLabel: 'GitHub',
        },
      },
    },
  },
},
```

Замените имя и адреса. `metaLine` — статус вверху личной панели; `who`, `what`, `ethos` и `now` — кто вы, чем занимаетесь, ваши принципы и текущие дела; `contactLead` — приглашение связаться, `signature` — подпись. `ethos` — массив строк, новый массив заменяет все элементы.

Абзацы и подпись — обычный текст. `\n` переносит строку, `\n\n` оставляет пустую. Markdown и HTML не разбираются, `<br>` не используйте. Пример меняет только упрощённый китайский; другим языкам нужны свои тексты, автоматического перевода нет. Отсутствующие поля дополняются правилами отката языка.

Оконные элементы About закрывают, сворачивают и разворачивают панель, сохраняя состояние локально в браузере. Вывод AI и прогресс загрузки в инструментах — демонстрация взаимодействия темы; заполнение текста не подключает AI-сервис. Декодирование обрабатывает ввод локально в браузере.

Если About не нужен, задайте `enableAboutPage: false` в `theme`; стандартное значение `true`. После отключения маршрут, общая навигация и связанные входы контактов About исчезают. Ваши ссылки в тексте или подвале автоматически не удаляются: проверьте их отдельно.

Поля контента — в [справочнике About](/ru/blog/config-about/#about-content), подсказки команд и тексты просмотрщика — в [справочнике терминала](/ru/blog/config-terminal/#messages).

## 3. Настройте Decoder и карточки чтения

Decoder Lab находится на `/zh/decoder/` и включён по умолчанию. Его оформление отдаёт дань шифропанкам и пионерам цифровой свободы; локальная обработка и образы одноранговых сетей отражают самостоятельное владение инструментами и данными.

Инструменты декодируют текст, объясняют поддерживаемые вызовы токенов и проверяют формат адресов без RPC, кошелька или API Key. Они не запрашивают баланс, не выполняют транзакции и не доказывают владельца адреса; введённая calldata не подтверждает реальное поведение контракта.

`enableDecoderPage: false` в `theme` независимо отключает страницу и связанные входы темы. Отключение About не отключает Decoder и наоборот. Пользовательские ссылки обслуживайте сами.

Текст посвящения и карточки задаются для языка, например замена китайского списка:

```ts
i18n: {
  locales: {
    zh: {
      messages: {
        decoderPage: {
          readings: {
            tribute: '思想与代码，让隐私和自由更进一步。',
            links: [
              { title: '我的阅读资料', href: 'https://example.com/', author: '作者名', year: '2026' },
            ],
          },
        },
      },
    },
  },
},
```

`tribute: ''` скрывает посвящение, `links: []` — карточки, отсутствие полей оставляет стандартные данные. У элемента обязательны `title` и `href`; `author`, `year` и `cover` необязательны. `cover` принимает встроенное имя (например `privacy-code` или `bitcoin`), public-путь или HTTPS-изображение. Без него карточка без картинки.

`links` заменяет список целиком, а не добавляет элемент; нужные старые записи укажите тоже. Это ссылки на предложенные вами материалы: тема не загружает и не перепечатывает их и не проверяет внешние ресурсы автоматически.

Типы полей, обложки и стандартный список см. в [справочнике Decoder](/ru/blog/config-decoder/#readings).

## 4. Настройте социальные ссылки и подвал

`social.links` — общий массив шапки и подвала с сохранением порядка. Для своего значка сначала добавьте `public/icons/community.svg`:

```ts
social: {
  links: [
    { href: 'https://github.com/yourname', label: 'GitHub', icon: 'github' },
    { href: 'https://example.com/community', label: '我的社区', iconSrc: '/icons/community.svg' },
  ],
},
```

`iconSrc` поддерживает локальные SVG, PNG и WebP из public с путём от `/`, без удалённого URL, query, fragment или закодированных символов. Он приоритетнее `icon` и сохраняет цвета изображения. Без обоих полей выводится текст. `label` задаёт доступное имя. Отсутствующий файл или неизвестный встроенный значок вызывают ошибку конфигурации.

Необязательный `rel` задаёт отношение ссылки, например `rel: 'me'` для своего Mastodon. Тема всегда сохраняет `noopener noreferrer` и не добавляет `me` по платформе автоматически. Проверку личности выполняет сама платформа: сайт должен быть опубликован, а в профиле должен быть реальный адрес страницы с обратной ссылкой. Результат проверки тема не гарантирует.

На мобильной ширине социальные ссылки шапки скрыты, в подвале остаются. `links: []` оставляет три некликабельных значка-заполнителя, не скрывая всю область.

### Подписи, описание и дополнительные ссылки подвала

```ts
site: { tagline: '保持好奇，持续记录。' },
theme: {
  footer: {
    showCredits: true,
    links: [{ label: '项目源码', href: 'https://github.com/yourname/your-project' }],
  },
},
```

- `site.tagline` — ваш обычный текст, пустая строка скрывает его; автоматического перевода нет. Старое стандартное `Built with Astro.` трактуется как встроенная подпись во избежание повтора.
- `theme.footer.showCredits` по умолчанию `true`, управляет подписями темы и Astro. Отключение оставляет копирайт, личное описание и дополнительные ссылки. Также управляет подписью темы в автоматических превью статей, но не меняет собственные изображения.
- `theme.footer.links` по умолчанию пустой массив. Ссылки между копирайтом и подписями независимы от социальных значков. Надписи остаются введёнными, не переводятся и не зависят от showCredits.

Имя копирайта — общее название сайта, год определяется при сборке. После изменения текстов, подписей или года нужна новая сборка и публикация.

Пути значков, поля ссылок и подписи см. в [социальных полях](/ru/blog/config-site-chrome/#social-fields) и [полях подвала](/ru/blog/config-site-chrome/#footer).

## 5. Включите музыкальный проигрыватель

Сначала поместите свой звук в `public/music/my-song.mp3`, затем объедините:

```ts
theme: {
  music: {
    enabled: true,
    tracks: [{ title: '我的一首歌', artist: '作者', src: '/music/my-song.mp3' }],
  },
},
```

Музыка по умолчанию отключена, тема не поставляет песни. Для трека нужны `title` и `src`, `artist` необязателен. Пустой плейлист не показывает проигрыватель. При добавлении песен сохраняйте нужные старые записи массива. URL без `public`, не путь диска и не страница обмена платформы. Допустим прямой HTTPS-аудиоадрес без пробелов и обратных слешей. Пустой заголовок или неправильный формат адреса вызывает ошибку, но правильный формат не гарантирует доступность файла.

Проигрыватель присутствует на страницах общего макета темы без переключателя по страницам; каждая новая страница начинается со свёрнутого состояния. При первом визите звук загружается только после PLAY. После конца трека включается следующий, после последнего — первый. На телефоне раскрытый проигрыватель временно скрывает кнопку наверх.

В одной сессии вкладки сохраняются трек, позиция и громкость. Если играло, переход или обновление пытается продолжить; после ручной паузы остаётся пауза. Это не бесшовное воспроизведение, браузер может запретить автозапуск. Без хранилища ручное воспроизведение работает, продолжение сессии не сохраняется.

Текущий код скачивает песню целиком и воспроизводит Blob, поэтому перемотка не зависит от серверного Range. Большие файлы увеличивают ожидание и память. Внешний сервер должен разрешать CORS; public-файлам того же сайта это не нужно. Сначала проверьте доступность аудио. Для отключения — `theme.music.enabled: false`.

Поля, статусы и ограничения продолжения см. в [справочнике музыки](/ru/blog/config-music/#track-fields).

## 6. Настройте количество и пагинацию

```ts
theme: {
  homeLatestCount: 3,
  blogPageSize: 10,
  pagination: {
    windowSize: 7,
    showJumpThreshold: 12,
    jump: { enabled: true, enterToGo: true },
    style: { enabled: true, mode: 'fixed', variants: 9, fixedVariant: 1 },
  },
},
```

`homeLatestCount` по умолчанию 3 — последние статьи главной; `blogPageSize` по умолчанию 10 — статьи на странице блога и тегов. Используйте разумные положительные целые. Они не меняют максимум три превью заметок на главной; размер списка заметок — `theme.fragments.pageSize`.

`windowSize` по умолчанию 7 задаёт окно номеров страниц и при рендеринге ограничивается 5–21, а не число статей. Быстрый переход появляется при true в `jump.enabled` и числе страниц больше `showJumpThreshold`, стандартно больше 12. `enterToGo` разрешает переход по Enter.

Стандартный стиль `random`; пример выбирает `fixed` для постоянного варианта. `sequential` выбирает по номеру страницы; клиентская инициализация `random` случайно выбирает заново, с возможными повторами. Без JavaScript остаётся статический стиль сборки. `variants` ограничивается 1–12, `fixedVariant` — текущим диапазоном вариантов.

`style.enabled: false` включает базовый стиль, а не отключает пагинацию. Blog, теги и Fragments делят эти настройки: учитывайте все три места.

Диапазоны, варианты и тексты см. в [справочнике списков](/ru/blog/config-blog-list/#pagination-window).

## 7. Отключайте только ненужные функции

Область каждого переключателя ниже; настройка одной функции не требует выключать всё.

| Путь                           | По умолчанию | Результат false                                                           |
| ------------------------------ | ------------ | ------------------------------------------------------------------------- |
| `theme.enableAboutPage`        | `true`       | Не создаёт About и скрывает связанные входы темы                          |
| `theme.enableDecoderPage`      | `true`       | Не создаёт Decoder и скрывает связанные входы темы                        |
| `theme.effects.enableRedQueen` | `true`       | Скрывает монитор Red Queen статьи, не все эффекты AI-страницы             |
| `theme.search.enabled`         | `true`       | Отключает вход поиска статей и создание индекса                           |
| `theme.toc.enabled`            | `true`       | Отключает стандартное оглавление; `toc: true` статьи может переопределить |
| `theme.tags.enabled`           | `true`       | Отключает входы/страницы тегов, не удаляя статьи                          |
| `theme.math.enabled`           | `true`       | Отключает математику Markdown/MDX                                         |
| `theme.socialImage.enabled`    | `true`       | Отключает автоматические превью статей, ручной ogImage работает           |

Например, только монитор отключается через `theme: { effects: { enableRedQueen: false } }` без изменения поиска, музыки или About.

Комментарии и заметки по умолчанию отключены; для остальных функций включать их не требуется. При необходимости прочитайте [Giscus](/ru/blog/starter-guide-4-giscus-comments/) и [заметки](/ru/blog/starter-guide-5-fragments/). Детали оглавления, формул и превью — в [руководстве статей](/ru/blog/starter-guide-2-languages-and-routing/) и [изображений](/ru/blog/starter-guide-images/).

## 8. Создайте собственную страницу для портфолио

Для отдельной страницы проектов выполните в корне:

```bash
npm run new-page -- projects
```

Создаётся `src/pages/[lang]/projects.astro` с макетом `base` по умолчанию и маршрутами включённых языков `/<语言代码>/projects/`, например `/en/projects/` и `/zh/projects/`. Заполните текст в Astro-файле. Он не переводится и не добавляется в верхнее меню автоматически. Добавьте ссылку в текст или footer links.

Для конкретного стиля есть `--theme`: например, `npm run new-page -- portfolio --theme cyber` создаёт другую Cyberpunk-страницу. Доступны `base`, `ai`, `cyber`, `hacker`, `matrix` — макет новой страницы, не глобальное переключение четырёх атмосфер. Slug — строчные латинские буквы, цифры, дефисы; вложенные пути вроде `projects/labs` допустимы. Не пересекайтесь со стандартными маршрутами пакета. Существующий одноимённый файл вызывает ошибку; не запускайте пять команд тем для одного пути подряд.

## 9. Проверьте сохранённые изменения

Откройте изменённую страницу в dev, проверьте тексты, ссылки и входы функций. Старые переопределения среды устраните по [первому руководству](/ru/blog/starter-guide-1-configure-your-site/). Отсутствующие значки, ошибки аудио и внешних ссылок проверяйте по путям/сети, а не повторной заменой всего конфига.

Перед публикацией остановите dev и выполните:

```bash
npm run doctor
npm run preview
```

doctor уже включает локальную подготовку, проверки и сборку; после успеха сразу повторять check/build не нужно. Поиск проверяйте в собранном preview; сам preview сайт не публикует. Для онлайн-изменений разверните весь `dist/` заново: локальное сохранение не меняет интернет-страницу.
